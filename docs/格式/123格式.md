> 定位与取舍的由来见 [../需求.md](../需求.md)；现有 `.jpwabc` 的对照见 [jpwabc.md](jpwabc.md)。
> **实现状态**（2026-09-12）：解析器、emitter、语义模型与语料迁移工具已落地
> （`src/j123/`、`src/model/`、`scripts/j123-migrate.mjs`），见
> [../模块/源格式-123.md](../模块/源格式-123.md) 与 [../模块/模型-scoredoc.md](../模块/模型-scoredoc.md)。
> **编辑器已接入**（拖入 `.123` 即排版，原文进原文出；见
> [../模块/源格式-123.md](../模块/源格式-123.md) 的「编辑器接入」）；MusicXML 侧迁移待补（需浏览器）。
> 规范在实现中改过两处：多连音的冒号由可选改为**必需**（见下方「`(` 的歧义」）；
> 空白不再表示符杠分组，符杠**按拍自动算**（2026-09-17，见 §4）。
> 同日为手写放宽：和弦可不带引号（§8.1）、版本头可省（§1）、字＋标点不必包 `{}`（§5.2）；
> 歌词改为**一行曲一行词**、跳音符改用 `/`、去掉 `@m,n` 锚点（§5.1、§5.2），`V:n` 重复出现即续写该声部（§7）。
> 2026-09-21 歌词行**去掉段号**：只留 ABC 原有的裸 `w:`（段号按出现顺序），同段续写用 ABC 的 `+:`，
> `w1:`／`w1-2:` 这类 `.jpwabc` 式写法不再接受（§5.1、§11）。
> 2026-09-23 对照 ABC 2.1 原文清一遍历史包袱（§0.1）：多连音改为 `(3: … )`、**`)` 必需**，与圆滑线只许嵌套（§4.1）；
> **可见休止不再占歌词对位格**（§5.1）；印刷段号只认 `<1.>`；落单的 `]` 不再当收尾线。
> 旧文件不兼容：不带 `)` 的多连音报错；休止处写了 `/` 的歌词从第一个休止起错一格（无诊断）。

## 0. 为什么是「ABC 方言」而不是标准 ABC

| 问题 | 结论 |
|---|---|
| 标准 ABC 能直接存简谱吗 | 不能。两处硬冲突：**`-` 在 ABC 是 tie、简谱是增时线**；**`_` 在 ABC 是降号、简谱是减时线**。简谱的 `1` 是调内度数，ABC 是绝对音名 |
| 那为什么还要沿用 ABC | ABC 的**字段头、歌词对齐、房号、演唱顺序、装饰记号、多声部**等机制成熟且够用，自造一套只会更差。本文逐项标注沿用的规范节号 |
| 样式为什么不写进 ABC | ABC 规范 §11 把全部版面/字体/间距指令标为 **VOLATILE**，原文明言它们「not formally part of the abc standard itself」「not standardised」「not necessarily portable」。样式改走独立样式表，见 [../样式机制.md](../样式机制.md) |
| 扩展怎么做才干净 | 用 ABC 官方扩展点 `I:`——规范 §3.1.17 规定「I: fields which are not recognised **should be ignored**」。与 `.jpwabc` 当年「原版 JP-Word 读到会忽略」是同一原则 |

**唯一的代价**：123 的音乐体不是合法 ABC 音乐体，标准 ABC 工具读不了它的音符。这是方言的本质，不必掩饰。

### 0.1 ABC 的哪些东西不继承

沿用 ABC 是为了借它成熟的机制，不是连它的历史包袱一起背。下面按 ABC 2.1 原文逐条过了一遍。
写成「ABC §x」的是 ABC 标准的节号，只写「§x」的是本文的节号。

**刻意不继承**——123 的目标之一是文本本身好读、好手写：

| ABC 的做法 | 为什么不要 | 123 |
|---|---|---|
| 多连音按个数收尾（ABC §4.13 `(p:q:r` 的 r） | 组的范围在原文里看不出来；组内时值不等时要另写 r，容易数错 | `(3: … )`，`)` 必需（§4.1） |
| 多连音默认比例看拍号（ABC §4.13：`(5`/`(7`/`(9` 复拍子占 3、否则占 2；`(6` 占 2） | 同一个写法在不同拍号下意思不同，读谱人要回头看 `M:` | 固定一张表，不看拍号（§4.1） |
| `L:` 默认音长，没写时按 `M:` 反推（ABC §3.1.7：小于 0.75 用 1/16，否则 1/8） | 简谱的时值本来就是相对的（`_` `-` `.`） | 不用 `L:`，写了忽略 |
| 破碎节奏 `>` `<`（ABC §4.4） | ABC 自己也说音长不等时「will produce undefined results」 | 附点、减时线直接写 |
| 空白决定符杠分组（ABC §4.7） | 手写时要为分组操心，删一个空格就改了谱面 | 按拍自动算（§4） |
| `[CEG]` 同时发声、`&` 小节内临时多声部（ABC §4.17、§7.4） | 简谱一个声部只印一路旋律 | 另起 `V:` |
| `z` 休止、`^ _ =` 变音 | 与简谱习惯不符；`_` 还和减时线冲突 | `0`、前置 `# b n` |
| 歌词跳音符 `*`（ABC §5.1） | 要按 Shift | `/` |
| 休止不跟词（ABC §5.1），但 2.1 另允许 `w:` 攒到曲末再对位 | 攒到曲末对位的那条扩展与 2.0 不兼容（ABC §10.6 自己承认）；词离曲太远也难对照 | 休止同样不跟词；但一行曲后面紧跟它的词，`$` 结束对位块（§5.1） |
| 首词以数字开头即段号（ABC §5.3，ABC 自己标为 VOLATILE） | 以数字开头的歌词会被误当段号 | 只认 `<1.>` |

**ABC 标为过时的，123 一开始就没收**（ABC §10）：`+…+` 装饰、`!` 断行、`\` 当通用续行符、
`A:` `E:` 字段、`Q:120` 这种按音长单位算的速度、野外文件用落单 `]` 收尾（123 不认，ABC 那一档作容错）。

**保留，但要知道的怪处**：

- `(1 (2) 3)` 是**首尾相接的两条弧**（1→2、2→3，ABC §4.11 的原例 `(c d (e) f g a)`），不是嵌套；
  只有一条弧开着时 `(1)` 才是单音弧。
- `x`（不可见休止）与 `X`（节奏音符）只差大小写。
- 单曲文件可以不写 `X:`。ABC 2.1 把这条列为 deprecated（ABC §10.5.1：再贴进一首就出错）；123 没有这个问题——
  首曲不写 `X:` 时，后面贴进来的那首只要带 `X:` 就会另起一首。只是首曲之后的每首都必须有 `X:`（§1）。
- 演唱顺序既有 `P:` 的段落语法（`P:((AB)3.(CD)3)2`），也有 `I:playorder`（§6）。
- 注记要加位置前缀：`"^rit."` 标在上方，`"_…"` 标在下方。

## 1. 文件结构

```
%123-1.0                    ← 版本声明（仿 ABC 的 %abc-2.1），可省；读取时忽略 BOM
X:128                       ← 曲号
标题：奇异恩典               ← 中文字段名 + 全角冒号，等价于 T:
T:Amazing Grace             ← 第二条 T: 是副标题
C:词 John Newton
K:1=F
M:4/4
I:style book.ss
F 5 1 3' 1 | C 3' 2 1- | $
w:奇异恩典何等甜
w:前我失丧今寻回
F 1' 6 5 3 | C 2--- | $
w:主恩/够用
w:赞美/主名
```

- **一首一文件**（`.123`），书级信息另放书清单 `book.json`（曲目与逐曲 meta 覆盖，见 [ss.md](ss.md) §8）；多曲拼一个文件也合法（`X:` 分隔，同 ABC tunebook）。
  **多曲文件里每首都必须有 `X:`**——分隔全靠它，缺了几首会连成一片。
- 编码 **UTF-8**（不沿用 `.jpwabc` 的 UTF-16LE）。
- 版本声明 `%123-1.0` **可以不写**（读入时当注释，手写省一行）；写出端照写。
- 写出端在每个 `$`/`$$` 后换行，一行曲一行源码，**紧跟着这一行的各段歌词**，方便与源图逐行对照（123 的代码换行不是谱面换行，见 §9；歌词怎么归行见 §5.1）。
- 注释 `%`（行首）与 `%%`（指令，等价 `I:`），沿用 ABC。

## 2. 中文支持

**字段名与冒号都接受中文形**——真实文本谱语料里已有用全角冒号的写法（头部 0.2%、曲行/词行 0.1%），
而中文字段名是本格式新增（语料里无先例），作为 ASCII 规范形的**别名**，解析时归一。

| 中文 | ASCII | 含义 | 中文 | ASCII | 含义 |
|---|---|---|---|---|---|
| `曲号：` | `X:` | 曲号 | `声部：` | `V:` | 声部 |
| `标题：` | `T:` | 标题（第二条为副标题） | `歌词：` | `w:` | 对齐歌词 |
| `副标题：` | `T:`(2nd) | 副标题 | `段：` | `w:` | 同 `歌词：`（都不带段号） |
| `词曲：` | `C:` | 词曲署名 | `顺序：` | `P:` | 演唱顺序 |
| `调：` | `K:` | 调号 | `演唱：` | `I:playorder` | 演唱顺序表（扩展） |
| `拍：` | `M:` | 拍号 | `注：` | `N:` | 注记 |
| `速度：` | `Q:` | 速度 | `样式：` | `I:style` | 引用样式表 |

- 冒号：ASCII `:` 与全角 `：` 等价。
- 字段值里的中文标点原样保留；歌词的收尾标点**并入前一字、不占音符格**（见 §5.3）。

## 3. 头部字段（沿用 ABC §3.1）

| 字段 | 沿用 | 123 的约定 |
|---|---|---|
| `X:` | ✅ | 曲号。补上 `.jpwabc` 缺的这一项 |
| `T:` | ✅ | 第一条为标题，第二条起为副标题。补上 `.jpwabc` 缺的副标题 |
| `C:` | ✅ | 词曲署名，多条并列（`.jpwabc` 是 `WordsByAndMusicBy` 一个字段塞多行） |
| `M:` | ✅ | 拍号。**混合拍**并排写几个（`M:3/4 4/4`，首个是起头拍号），后面可跟一段中文说明（`M:3/4 4/4 混合拍`）；辅助拍号包在括号里（`M:4/4 (2/4 1/4)`，同文本谱 `P: 4/4 ( 2/4 )`）。一个拍号时与 ABC 同形，曲中转拍号仍写行内 `[M:3/4]` |
| `L:` | — | **123 不用，写了忽略**：简谱时值由 `_`/`-`/`.` 相对表达（§0.1） |
| `Q:` | ✅ | 速度 `Q:1/4=76`；附点四分写 `Q:3/8=60`（同 ABC，拍单位随文档保存；`.jpwabc`、文本谱只认 ♩，写出时换成四分等值）。`.jpwabc` 把速度与表情挤在 `Expression` 一个字段里，123 分开（表情走 `N:` 或装饰） |
| `K:` | ✅ | **调号写首调**：`K:1=F`。也接受标准 ABC 形 `K:F`；`K:Em` 这种带 mode 的写法直接表达「调号同 G 大调、主音是 `6`」——**这正好解决「主音不一定是 1」**（语料里小调写法确有，`6=X` 占 0.01%），不必自造语法 |
| `P:` | ✅ | 演唱顺序，见 §6 |
| `V:` | ✅ | 声部，见 §7 |
| `N:` `Z:` `O:` `S:` `R:` `B:` `D:` `F:` `G:` `H:` | ✅ | 信息字段，语义同 ABC |
| `I:` | ✅ | 指令。标准的 `I:linebreak` 等照用；123 的扩展指令一律挂在这里。扩展 meta 写 `I:meta 键 值`（键见 [../样式机制.md](../样式机制.md) §9，如 `I:meta title-alt Crown Him with Many Crowns`），多值写多行。纸张：`I:meta page A4`（或「宽 高」pt）、`I:meta page-orientation landscape`、`I:meta page-margin 上 右 下 左`（pt）；五线谱尺寸：`I:meta staff-size`（谱表高 mm）、`I:meta lyric-size`（歌词 pt）；页眉字体：`I:meta font-title 16 Weibei SC`（`font-subtitle`/`font-scripture`/`font-credit`，「字号 [bold] 字体族」）——MusicXML 转来时由 `<page-layout>` 换算，写回 MusicXML 再还原 |
| `W:` `w:` | ✅ | `W:` 曲末歌词、`w:` 对齐歌词，见 §5。**`w:` 不带段号**，段号按出现顺序 |
| `+:` | ✅ | 续写前一条字段（ABC §3.1.18）。123 只用它续 `w:`（同一段拆几条写），别的字段续行报诊断 |
| `U:` | ✅ | 自定义符号 |

## 4. 音乐体（简谱原语，**本格式唯一偏离 ABC 之处**）

| 写法 | 含义 | 与 ABC 的关系 |
|---|---|---|
| `1`–`7` | 唱名（调内度数） | 偏离（ABC 是音名 `CDEFGAB`） |
| `0` | 休止；**不占歌词对位格**（§5.1） | 偏离（ABC 是 `z`）；不跟词同 ABC §5.1 |
| `#` `b` `n` 前置 | 升 / 降 / 还原，如 `#4` `b7` | 偏离（ABC 是 `^` `_` `=`） |
| `'` `,` 后置 | 高 / 低八度点，可重复 | **同形同义**（ABC §4.1） |
| `_` | 减时线，每条减半 | ⚠️ **冲突**：ABC 的 `_` 是降号 |
| `-` | 增时线，每条加一拍 | ⚠️ **冲突**：ABC 的 `-` 是 tie |
| `.` | 附点 | 近似（ABC 是 `a3/2` 或 `>`） |
| （空白） | **只为好读，不表示符杠分组**；符杠（减时线连杠）**按拍自动算** | ⚠️ **偏离 ABC §4.7**（ABC 连写即同杠）。手写不必操心分组，`1_2_` 与 `1_ 2_` 等价 |
| `` ` `` | 可读性分隔符，**解析时忽略** | 沿用 ABC §4.7 |
| `"Am7"` / `Am7` | 和弦，前置于所属音符；不带引号时**大写 A–G 开头、到空白为止、必须跟空格**，见 §8.1 | 引号形沿用 ABC §4.18；不带引号是 123 扩展 |
| `y` | **无时值占位符**：不占时间、**不占对位格**，专供挂和弦与记号 | **沿用 ABC**（§4.14 的 spacer） |
| `x` | **不可见休止**：占时值、**占对位格**（可跟词），对应文本谱的隐藏休止 `8`。要给空拍配字就写它 | **沿用 ABC** 的 invisible rest（但 ABC 里它不跟词） |
| `X` | **节奏音符**：有声、无音高（文本谱写 `X`、番茄写 `9`）。语料里真实存在，不可省 | 扩展（ABC 的打击乐要靠 `K:perc` + 音高映射，对简谱太绕） |
| `\|` `\|\|` `\|]` `[\|` `\|:` `:\|` `::` | 小节线族 | **沿用 ABC §4.8**。`\|::`/`::\|` 表示唱三遍 |
| `[\|]` | 不可见小节线 | **同形同义**（ABC §4.8 与 `.jpwabc` 巧合一致，语料 3.2%） |
| `.\|` | 虚线小节线 | 沿用 ABC |
| `( )` | 圆滑线/延音线，可嵌套、可同音起止 | **沿用 ABC §4.11** |
| `(3: … )` | 三连音（`(N:` 为 N 连音，比例非默认写 `(n:p:`）；**`)` 必需** | 改自 ABC §4.13，见 §4.1 |
| `{6,}` `{2_}` | 倚音 | 沿用 ABC 的花括号倚音（内容换成简谱数字）。不占拍；时值**相对倚音单位（八分）**，同 ABC §4.12「倚音长度照普通音符写、单位另定」：`{2}` 八分、`{2_}` 十六分、`{2__}` 三十二分（文本谱 `{2/}`、ABC `{d/}` 同义） |
| `!fermata!` `!accent!` 等 | 装饰与记号 | **沿用 ABC §4.14**，见 §8 |
| `$` | 换行 | 沿用 ABC（`I:linebreak $`），见 §9 |

### 4.1 多连音 `(3: … )`

组内按**印出来的时值**写，用 `)` 收：

| 写法 | 读作 |
|---|---|
| `(3: 1_ 2_ 3_)` | 八分音符三连音，占一拍 |
| `(3: 7, 6, 5,)` | 四分音符三连音，占两拍 |
| `(3: 1 2_)` | 组内时值可以不等：共 1.5 拍的时值 × 2/3 = 一拍 |
| `(2: 1. 2.)` | 二连音（6/8 里常见），占三个八分 |
| `(5:4: 1__ 2__ 3__ 4__ 5__)` | 比例不是默认值时写 `(n:p:`，读作「n 个音占 p 个的时间」 |
| `(3: (1_ 2_) 3_)` | 弧在组内 |
| `((3: 1_ 2_ 3_) 4)` | 弧包住整组 |
| `(1 2)` | 圆滑线，包住 `1` 与 `2` |
| `(1 (2 3) 4)` | 嵌套圆滑线 |
| `(1 (2) 3)` | 两条首尾相接：`1→2`、`2→3`（ABC §4.11；只有一条开着时 `(1)` 才是单音弧） |

- **起头以冒号收尾**：简谱的音符是数字，裸 `(3` 分不清是「三连音」还是「圆滑线 + 音符 3」；
  `(3:2 1` 里的 `2` 也是音符，不是比例。两个既有格式都为此加过区分标记（`.jpwabc` 写 `{(3}`、文本谱写 `(y3…)`）。
- **`)` 必需，与圆滑线同一套嵌套**：`)` 收最近开的那个括号。组的范围在原文里一眼看得见，
  也不用像 ABC 那样数「作用于随后几个音」。漏了 `)` 报「多连音缺 `)`」，多连音不能跨小节线。
- **只许嵌套、不许交叉**：弧从组内起、到组外止（或反之）写不出来；从别的格式转来时，写出端把弧截到组的边界，
  并在丢失清单里报出来。
- **默认比例**：二连音、四连音占 3（复拍子里用），其余占小于 n 的最大 2 的幂（3→2、5→4、6→4、7→4）。
  **不看拍号**；比例不是这个值就写 `(n:p:`。
- 组内所有占时值的元素（音符、`0`、`x`、`X`、增时线）都按比例折算；多连音可以嵌套，比例相乘。
- 以前的写法（不带 `)`、按个数收尾；完整形 `(3:2:3`）**不再接受**，读到报「多连音缺 `)`」。

## 5. 歌词与对位

> 对位（歌词↔音符逐音对应）是简谱歌本的命门：一个音节错位，整行就错。
> 本节在 ABC §5 的基础上补中文规则。

### 5.1 段号（按出现顺序，纯 ABC）

**一行曲一行词**（同 ABC §5.1「`w:` 对齐紧挨在前的那行音乐」，同文本谱 `Q:` 行后跟 `C1:` `C2:`）：

```
6 (6_ 5_) 6 1' | 6 5_ 6_ 3- | $
w:日光/之下有一个谜，
w:日光/之上有个奥秘，
3'_ 5_ 5_ 3'_ (2'. 3'__ 2'__) | 1'_ 6_ 5_ 6_ 3- | $$
w:眼看看不饱，//耳听听不足，
+:（`+:` 续写上一段，长行可以拆开写）
w:（这是第 2 段）
```

- **`w:` 不带段号**：一行曲下的第 1 条 `w:` 是第 1 段、第 2 条是第 2 段……
  （ABC §5.1「同一行音乐下的几条 `w:` 依次是各段」）。
  `.jpwabc` 式的 `w1:` 与段号区间 `w1-2:` **不再接受**（读到报诊断、整行丢弃，见 §11）。
- **一行曲**：从上一批 `w` 行之后起、到 `$`/`$$` 为止的音乐行（没写 `$` 的长行可以折成几条代码行）。
  紧跟其后的 `w` 行从**这一行曲的第一个音**起对位。
  - 这一行某段没词（前奏、只唱一段的行）：**写一条空 `w:` 把段位顶住**——段号是数出来的，
    少一条后面的段就整体前移一段。行尾整段都没词的不必写。
  - 行首不配字的音用 `/` 补；行尾的空位不必写。
  - 同一段拆几条写：第二条起用 ABC 的续行字段 `+:`（§3），接着上一条往下挂。
  - 字比这一行的音多：多出的丢弃并报诊断。行末 melisma 的 `_`（`主_`，延长到下一行第一个音）不算多。
  - **`$` 结束一行曲**（同 `.jpwabc`）：其后的 `w` 行只挂这一行；同一代码行里 `$` 之后的音符另起一行曲，
    要配词就在它后面另写 `w` 行——不与前一行共用。（ABC 不同：`w:` 对的是它前面那条代码行，行内 `$` 只是谱面换行。）
- **对位格**：音符（含节奏音符 `X`）与不可见休止 `x` 各占一格；**可见休止 `0`、倚音、`y` 不占**
  （同 ABC §5.1「syllables are not aligned on grace notes, rests or spacers」，也同文本谱）。
  所以休止前后的字直接连写，不必写 `/`；真要给空拍配字，把那个休止写成 `x`。
- **不支持锚点**（`.jpwabc` 的 `W1@m,n`）：对位起点完全由位置决定。
- **一行词供多段共用**（副歌）没有区间写法：**每段各写一遍**（ABC 就是这样；写出端自动展开）。
- **印刷段号**：段首写 `<1.>` 即在歌词前印出「1.」而不占音符格（文本谱语料 55.6% 这么写）。
  **只认这一种写法**：ABC §5.3 的「首词以数字开头」（ABC 自己标为 VOLATILE）与行首 `"1."` 都不认——
  前者会把以数字开头的歌词当成段号，后者和贴前字的直引号（§5.2）冲突。

### 5.2 对齐符号

| 符号 | 含义 | 来源 |
|---|---|---|
| （空格） | 音节分隔 | ABC §5.1 |
| **CJK 连写** | **每个汉字自成一个音节，无需空格** | **123 扩展**（ABC 要求空格分词；中文一字一音，连写更自然） |
| `-` | 拉丁词内断音节 | ABC |
| `_` | 前一音节延长到这个音符（melisma 续记号） | ABC。对应 `.jpwabc` 的 `/`（语料 81.5%） |
| `/` | 跳过一个音符（该音符不配字） | **123 扩展**：同文本谱诗歌本的 `/`（语料 77.7%），免 Shift。ABC 是 `*`（旧文件里的 `*` 仍按跳音符读，但报诊断） |
| `\/` `\-` | 字面的斜杠、连字符（`and\/or`） | ABC 的 `\-`；`\/` 是 123 扩展 |
| `{多字}` | 多字挤在一个音符下 | 123（同文本谱；语料 0.6%）。ABC 的 `~` 与 `\-` 同义，也接受 |
| `\|` | 推进到下一小节（对齐自检） | ABC |

**标点一律不占音符格**（这是对位正确的前提）：

- 收尾标点并进前一字；直引号 `"` 分不出开闭，一律贴前字
- 左引号 `“`/`‘` 领起后一字
- 行首没有前字可并的标点（`《圣经》…` 的 `《`）挂在后一字之前，**但不并进那个字的文本**——
  并进去会改变音节字数，让下面「多字并一格」的判断反复翻转
- **多字并一格要包 `{}`**（`{1.圣}`）：CJK 是逐字成音节的，不包起来读回就被拆散，
  后面所有字前移一格、末尾溢出丢字。**「一个字 + 标点」不算多字**，`哦，` `“主` `主。”` 直接写，不必包

### 5.3 中文排版规则（格式层面的约定）

- **收尾标点并入前一字**，不单独占音符格（`主,` `祢。` `亚!`）。
- 左引号领起后字、右引号贴前字。
- 一字多音用 `_`，一音多字用 `{}`。
- **输入法**：中文标点状态下按 `/` 多半打出 `、`，而 `、` 是收尾标点、会悄悄并进前一字、少占一格；
  `_` 也可能变成 `——`。写对位符号时切到英文标点。
- 这三条的排版实现见 [../实现/歌词标点挤压.md](../实现/歌词标点挤压.md)；格式只负责**不把标点写成独立音节**。

## 6. 演唱顺序（`.Repeat` 的完整落地）

谱面的 `|: :|` 与房号**只是谱面记号**；「按什么顺序唱、第几遍配第几段词」由本节决定。

### 6.1 先用 ABC 标准

| 需求 | 写法 | 规范节 |
|---|---|---|
| 段落与遍数 | 头部 `P:A2`（=AA）、`P:(AB)3`、`P:((AB)3.(CD)3)2`；曲体内 `P:A` 标段落 | §3.1.9 |
| 每遍不同结尾 | `[1 … :\| [2 … \|]`；多房 `[1,3` `[1-3` `[1,3,5-7` | §4.9 §4.10 |
| 第 n 遍唱第 n 段词 | 相邻多条 `w:`，第一条用于第一遍 | §5.2 |
| 跳转 | `!segno!` `!coda!` `!D.S.!` `!D.C.!` `!dacapo!` `!dacoda!` `!fine!` | §4.14 |

### 6.2 ABC 表达不了的三项 → `I:playorder`

```
I:playorder 1-4 v1 | 1-4 v2 page | 11.2-20 v4 | 11-20.1 v5
```

| `.jpwabc` `.Repeat` | 语义 | 语料频次 | 123 |
|---|---|---|---|
| `1-4V1` | 遍 + 配第几段词 | 7/568 首用 `.Repeat` | `P:` + 相邻 `w:`（标准） |
| 段号非顺序（第 3 遍配第 1 段词） | 顺序映射表达不了 | **6/568 首** | `I:playorder` 的 `v<n>` |
| `1-4V1P` 的 `P` | **这一遍唱完换页** | 有 | `I:playorder` 的 `page` |
| `11.2-20V4` | 从第 11 小节第 2 个音符接入（skip） | 500 首里 0 次 | `I:playorder` 的 `m.n-` |
| `11-20.1V5` | 只唱到第 20 小节第 1 个音符（limit） | 500 首里 0 次 | `I:playorder` 的 `-m.n` |

- skip/limit 虽在 500 首里未出现，仍须保留：**MusicXML 的 `<ending>` 只能整小节，表达不了它**，
  123 是这层语义的唯一无损载体。
- 三者共存时的优先级：`I:playorder` > `P:`/`[N` > 从谱面记号推导。
- **换页口径只在一处判**（`src/jianpu/expand.ts::walkPlay`），不许散到排版器。

## 7. 多声部

- `V:1` … `V:4` 分声部，属性沿用 ABC：`name=` `subname=` `stem=` `clef=`
  （规范要求「**must gracefully ignore specifiers they don't understand**」，扩展安全）。
- **`V:n` 再次出现是续写该声部**（ABC 语义），所以多声部也能逐行交错写，各声部的词跟在自己那行后面
  （同文本谱 `Q1:` `Q2:` 后跟 `C1:`）；弧可以跨行、中间隔着别的声部。写出端就这么写：

  ```
  V:1
  1 2 3 (4 | $
  w:主啊我要_
  V:2
  5, 6, 7, 1 | $
  V:1
  5) - 6 5 | $
  w:/来到
  V:2
  3, - 4, 3, | $
  ```
- 并排分组用 `%%score {(S A) (T B)}`（SATB），沿用 ABC §11.1。
- 临时伴奏层对应文本谱 `{bz…}`（语料 0.05%，低频）。
- 语料实证：四声部占 0.05%、二声部 0.2%——**少数但真实存在**，不能不支持。

## 8. 和弦、力度、记号

### 8.1 和弦锚定（含**无对位音符**的情形）

和弦**前置**于它所属的音符（文本谱是后置，导入时转换），两种写法等价：

- **不带引号**（手写推荐）：`Am7 1`。规则是**大写 A–G 开头、到空白为止、后面必须跟空格**。
  A–G 在 123 音乐体里原本没有用处（音符是数字），所以不会与别的记号冲突；
  「到空白为止」是因为和弦名里常有数字与 `b`/`#`，`G71`、`Bb3` 粘在一起切不开。
  名字要合规（根音 + 性质/延伸 + 可选 `/低音`，如 `F#m7b5` `Gsus4` `E7(#9)` `Bb/C`），否则报诊断。
- **带引号**（ABC 形）：`"Am7"1`。不合规的名字（`"N.C."`、带空格的）只能这样写。写出端能不带引号就不带。

和弦与音符并非一一对应，四种情形都要能写：

| 情形 | 写法 | 语料实证 |
|---|---|---|
| 挂在音符上 | `Am 1 3` | 绝大多数 |
| 长音中途换和弦（挂在增时线上） | `5 F - C -` | 190 次 |
| 挂在休止上 | `Am 0` | 248 次 |
| **完全没有对位音符**（小节起始、跨行延音、只有和弦的前奏/间奏） | `Am y`——`y` 是**无时值占位符**，不占时间、不画音符，只承载和弦 | 72 次（行首和弦） |
| 和弦与旋律分行写 | `s:"Am" / / "F" /`——符号行，对齐规则同歌词行（`/` 跳音符） | 沿用 ABC §4.15 |

`y` 与 `s:` 两条都是 ABC 标准机制，不是自造。

### 8.2 力度与渐强渐弱

`!p!` `!mp!` `!mf!` `!f!` `!ff!` `!fff!`（ABC 给了明确的 MIDI 音量映射）、
`!crescendo(!` `!crescendo)!` `!diminuendo(!` `!diminuendo)!`。对应文本谱的 `&p`/`&mf`/`&cresc`。

### 8.3 音符上的记号：几种记法都认

音符上的记号写在音符前面（`!fermata!5`）。**同一个记号有几种记法，都认、意思相同**；读进来原样记下，
写回时**作者写的是哪种就还是哪种**。排版、转 MusicXML、转文本谱之前统一归一（`model/deconames.ts`）。

| 意思 | 文本谱短名 | ABC 名 | 中文名 | 也认 |
|---|---|---|---|---|
| 延长 | `!yc!` | `!fermata!` | `!延长!` `!延长记号!` | `!invertedfermata!` |
| 重音 | `!zy!` | `!accent!` | `!重音!` | `!>!` `!emphasis!` `!strong-accent!` |
| 顿音（▼） | `!dy!` | `!staccato!` | `!顿音!` | `!staccatissimo!` |
| 保持音 | `!bc!` | `!tenuto!` | `!保持音!` | |
| 呼吸 | `!hx!` | `!breath!` | `!呼吸!` `!呼吸记号!` | `!breath-mark!` |
| 颤音 | `!tr!` `!cy!` | `!trill!` | `!颤音!` | `!trill-mark!` |
| 上波音 | `!sby!` | `!uppermordent!` | `!上波音!` | `!pralltriller!` `!inverted-mordent!` |
| 下波音 | `!xby!` | `!lowermordent!` | `!下波音!` | `!mordent!` |
| 上滑音 / 下滑音 | `!shy!` / `!xhy!` | — | `!上滑音!` / `!下滑音!` | `!scoop!` / `!falloff!` |

- 文本谱短名与文本谱的 `&xx` 同名（名称取符号中文名的拼音首字母），从文本谱转来的就写短名；
  「也认」一列是 MusicXML 的元素名，从 MusicXML 转来、没有 123 原写法的记号就写它（波音、颤音写短名）。
- 拉丁字母的名字不分大小写。认不出的名字原样保留、往返不丢，但不画。
- 文本谱的 `&xx` 在语料里实际用到 30 余种（`&yc` 延长 17.2% 最高，其余多为加 `g`/`d` 后缀的上/下位变体，
  上下位由排版决定、不进格式）。表外的几类：`&rit` 这类术语写注记 `"^rit."`；伴奏括弧 `&zkh` `&ykh` 见 §7；
  力度见 §8.2；跳转记号见下。

跳转记号：`!segno!`（文本谱 `&hs`，花 S 记号 𝄋）、`!coda!`（`&ty`，⊕）、`!D.C.!`（`&dc`）、`!D.S.!`（`&ds`）、`!fine!`。
跳转记号挂的是**小节线**（`Barline.ornaments`），不是音符。写在线的哪一侧决定它挂哪条线：
左线的写在线**之后**（`| !segno! 6 …`，segno/coda 是跳转目标），右线的写在线**之前**
（`… 6 !fine! |]`，唱到这里才跳）。两边的名字表见 `abcfamily/jumpmarks.ts`。

`.jpwabc` 的四个拼音名记号只有 `{YanYin}` 真正用到（15.0%）→ 延长；
`DunYin`/`BoYin`/`ZhongYin` 语料 0 次，记入 §11。

## 9. 断行与分页

| 需求 | 写法 | 来源 |
|---|---|---|
| 保留原断行（「原始排版」档） | `I:linebreak $` + 曲体内 `$` | **ABC §6.1.1 的默认与推荐值** |
| 全自动断行（「按乐句重排」档） | `I:linebreak <none>` | 同上。ABC 自己就把这两档分开了 |

| 小节中间换行（原图行末没有小节线） | 在那个音后面写 `$`，不补小节线 | 同 `.jpwabc`：谱面在原位换行，小节不拆；模型记在 `Chord.lineBreakAfter`（另在下一小节留一份小节级换行） |
| 每页行数 | `I:linesperpage 4` | 扩展（对应 `.jpwabc` 的 `.Layout` `LinesPerPage`，语料 53.0%） |

## 10. 样式

格式里**只留一个引用点**，样式本体在独立样式表：

```
I:style kl2020.ss                          ← 整首引用
```

路径相对谱文件所在目录（编辑器打开时按它装诗集样式表，见 [../模块/样式与设置.md](../模块/样式与设置.md)）。
样式表的语法见 [ss.md](ss.md)。样式表只管版式；某段歌词换字体、小音符这类逐曲修改写在谱面数据里，不走样式。

页眉页脚（文本谱的 `XL/XR/TL/TR/BL/BC/BR`，语料 绝大多数用到）也走 `I:` 扩展：
`I:indexleft` / `I:indexright` / `I:topleft` / `I:topright` / `I:bottomleft` / `I:bottomcenter` / `I:bottomright`。

对应文本谱的 `FontSize:`（26.4%）、`Margin:`（20.8%）、`Space:`（22.2%）、`Off:`（25.8%）——
这些**文档内样式指令在语料里是高频的**，所以局部覆盖必须支持，但样式的**定义**归 [../样式机制.md](../样式机制.md)。

## 11. 已知不表达（按语料频次裁定）

**语料里 0 次、刻意不进 123**：

| 项 | 出处 | 理由 |
|---|---|---|
| `.jpwabc` 的和弦 `[1 3 5]` | 文法有、实现无、语料 0 | 和弦走 `"Am7"` 符号，不做音符堆 |
| `.jpwabc` 的节奏音符 `x`/`X` | 文法有、实现无、语料 0 | `.jpwabc` 那两个记号不进 123；**节奏音符本身 123 是支持的**，写大写 `X`（文本谱语料里有） |
| `{DunYin}` `{BoYin}` `{ZhongYin}` | 语料 0 | 需要时用 §8.3 的记号名（`!dy!` `!staccato!` `!顿音!` 都行） |
| 歌词的显式段号 `w1:` 与段号区间 `w1-2:` | `.jpwabc` 的 `W1-6:`（0.2%）、文本谱 `C1-2:` | ABC 只有裸 `w:`（段号按出现顺序）。**一行词供多段共用时逐段各抄一遍**，信息不丢、只是写法变了 |
| `{C:…}` JP-Word 微调参数 | 语料 0，且现会污染音符解析 | 版面微调归样式表 |
| MusicXML 的 `<wedge>` `<pedal>` `<octave-shift>` `<glissando>` `<arpeggiate>` `<staves>` | 500 首里 0 次 | 不背包袱；需要时按 ABC 装饰补 |

**语料高频但刻意不做**：

| 项 | 语料 | 为什么不做 |
|---|---|---|
| 文本谱的强制连拍 `~` / 强制断拍 `^` | `^` 45.3%、`~` 17.2% | 它们只控制**减时线（符杠）怎么分组**，不动音高与时值。123 的符杠**一律按拍自动算**（同 `.jpwabc`），空白也不参与分组——手写时不必为分组费心。副作用是好的：曲行不再用 `~`，与歌词行 `~`（多词一音，§5.2）的语义冲突随之消失 |

**保留但低频**（语料有、优先级低）：跨行延音的和弦锚点、`{bz…}` 临时伴奏层、多连音 N≠3、
`.Repeat` 的 skip/limit。

**暂不表达**（需要时再提级）：自由节奏/散板（现状也无）、歌词对齐位 `{…[…]}`（`.jpwabc` 语料 0.9%，
且现有实现解析后无消费方）、一小节内的临时多声部（ABC §7.4 的 `&`，对应文本谱的 `{dsb…}`；123 的词法不认 `&`，
需要时另起 `V:`）。

## 13. 验收

规范条目由**语料频次倒推**而来（`node scripts/census-123.mjs`，见 [../../scripts/census-123.mjs](../../scripts/census-123.mjs)）。
落地时的验收判据：

1. **特征覆盖 100%**：三批语料全量（文本谱语料全部歌本、500 首的 568 份 `.musicxml` 与 568 份 `.jpwabc`）
   用到的语义特征，必须条条有 123 写法，或显式记入 §11，**不许静默落空**。

   《沧海一声笑》（`.Repeat` 推三房）、《小兔子乖乖》（`:|&dc` 展三遍、第三遍无词）。
3. **往返不回退**：`pu-parse-check.mjs`、`xml-roundtrip.mjs`、`line-check.mjs` 三条基线零回退。

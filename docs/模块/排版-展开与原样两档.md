# 排版：「展开 / 原样」两档

## 职责

**两档的唯一语义是「排版方式」**，不是版式主题、也不是文档格式的分支：

| 档 | 语义 | 用途 |
|---|---|---|
| **展开** | 反复与多段歌词**逐遍展开**，一段歌词一遍谱、逐遍成页 | 投影（一屏一段） |
| **原样** | 按原谱排一遍，多段歌词叠在同一条谱行下、反复不展开 | 印刷歌本 |

**`.jpwabc` 与文本谱两种格式语义完全一致**，公共那一半在 `src/jianpu/`。
纸张、字号、配色**不属于这两档的分野**——它们是独立设置项，两档各记各的一套。

## 入口

| 文件 | 作用 |
|---|---|
| `src/jianpu/profile.ts` | 档位 `JianpuLayoutMode = "expanded"\|"original"`；`jpProfile`/`puProfile` 只是两种格式各记的档名 |
| `src/layout/jianpupages.ts::layoutExpandedPages` | **展开档排页，两种格式共用一个**（吃简谱引擎输入 + 展开档样式；由 `ScorePainter` 的 `expanded` 请求调用） |
| `src/jianpu/vertical.ts` | 纵向分页 `paginate`（只认块的占位盒，两格式共用） |
| `src/jianpu/expand.ts` | `walkPlay` 按 `PlayItem[]` 逐遍逐小节回调；原样档走 `identityPlan` |

原样档都由 `layout/painter.ts::ScorePainter` 排，布局算法两套：`.jpwabc` 与**单声部**的 123/ABC 走简谱引擎
（后两者经 `jianpuInputOfDoc` 投影，由 `FormatCaps.originalLayout` 与 `App._originalOnJianpu` 判）；文本谱、MusicXML 与多声部的 123/ABC
走原样文档布局 `layout/original/`（`place.ts` 定位、`compose.ts` 构图，印刷原版观感）。

## 关键判据

- 「这首歌唱成什么样」**一律由 `score/playorder.ts` 从 `ScoreDoc` 推**：简谱形状（文本谱/123/ABC/`.jpwabc`）经 `model/playsong.ts::playDataOfSong`
  （`.jpwabc` 照 `.Repeat` 或按段逐遍），MusicXML 形状经 `model/playdoc.ts::playDataOfDoc`，投影时填进引擎输入的 `playData`。
- **换页口径只在 `walkPlay` 里判**：`endOfPass`（`.Repeat` 的 `P`、按段数逐遍）与**往回跳**
  （反复、D.C./D.S.）处换页；遍号变了但往前接着唱的（二房后的尾段）**不换**。源里的 `$` 强制分页另算。
- 四档视图 `ViewMode` 是**两组正交状态的组合**，不是四个视图：展开/原样走简谱（或文本谱）排版器，
  五线谱/混排也走 `ScorePainter`（差别只在 `mixedShowJianpuLayer`）。默认**展开**。
- **纸张宽度全仓一份**：`styles.css` 的 `--score-page-max`（960px），四档连同识别叠加视图共用。
  变量里**只放上限、别把整条 calc 放进去**——自定义属性里的 `var()` 在声明它的那个元素上就替换掉了。
- 纸与字号两档各记各的：展开档取 `PAGE_RATIOS`（16:9/4:3，1 单位 = 1pt，**恒分页**）；
  原样档取 `PAPER_SIZES` 实际尺寸 + 一档**长图**（出厂默认，宽 1000 = `layout/original/metrics.ts::JIANPU_DEFAULTS.page.width`）。
  **「换纸」与「要不要分页」本来就是同一个决定**，所以长图是纸张列表里的一档而非勾选框。
- 导出 PPTX 取的是**展开档**那一套，哪怕屏幕正停在原样档。
- 「每页行数」（写进 `.Layout`）**只归展开档**——原样档行数由内容与纸说了算，人为定死只会把谱挤坏。
- 原样档分页时标题块排在**第一页顶上**而不是另起标题页（`LayoutOptions.bookHead`），首页可用高度按量出来的块高扣减
  （`firstPageHeadroom`，由 `jianpupages.ts::layoutOriginalPages` 填）。纸顶照 500 首重排排（`jianpupages.ts::bookHead`）：标题居中、
  **调号拍号在左**（`1=♭B ⁴⁄₄`，升降号提到音名之前、小一号并抬高）、**词曲署名右对齐逐行**，调号拍号基线与最后一行署名齐。
  挂标题块要**另包一层 Group**（见 [排版-简谱引擎.md](排版-简谱引擎.md)）。
- 展开档笔画见 `style/jianpu.ts` 的 `pptx` 预设，几处**刻意背离**：小节线高度用原样档那份、三种点同半径、
  减时线与旧式八度点阶梯照 2019 年成品 .pptx。

## 回归

回归脚本、语料与基线不在本仓库（本地私有仓库）。

## 已知限制

- 文本谱展开档**只排一条旋律**（`Layout` 只排 `parts[0]`）；和弦与首调号拍号不出现
- `.jpwabc` 某些曲目的歌词归属语义未定（同一小节被两条 W 行认领时谁优先）
- D.C. 那一遍无词时整页无词（「D.C. 该配哪几段词」待定）
- 多声部对齐（`alignVoices`）与分页在简谱引擎、原样文档布局（`layout/original/place.ts`）里各自独立实现，
  未收敛成共享拍位列／分页算法；合并需要新夹具，未立项

具体曲目的未修版面问题见 [../遗留问题.md](../遗留问题.md)。

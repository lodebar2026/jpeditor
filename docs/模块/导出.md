# 导出

## 职责

页面树/模型 → PNG / PDF / 矢量 PPTX / MIDI / MusicXML / `.jpwabc` / 文本谱原文。

## 入口

| 函数/文件 | 作用 |
|---|---|
| `EXPORT_ITEMS` | `src/editor/export.ts` 导出菜单（PPTX / MIDI / MusicXML / JPWABC / PNG / PDF，外加**跨格式另存为** 123 / ABC） |
| `buildMusicXml(app)` | `src/editor/export.ts` 当前文档 → MusicXML：有底本且没改过给底本，否则经唯一写出端整份重写 |
| `scoreDocToMusicXml(doc)` | `src/model/toxml.ts` **MusicXML 唯一写出端**。简谱来源先经 `model/xmlproject.ts` 投成 MusicXML 形状；`.jpwabc` 先经 `jpwToScoreDoc`（速度、由 `.Repeat` 反推的房号、绝对音高都由投影补） |
| `planSave(doc, target)` | `src/model/capability.ts` 另存为会丢什么 → 确认对话框 |
| `buildPptx(painter)` | `src/editor/pptx.ts`（455 行）页面树 → OOXML 形状，fflate 打包 |
| `toMidi(src, opts)` | `src/score/midi.ts` 标准 MIDI 字节（与试听共用同一份 `PlaySource`，note-on 力度取力度记号） |
| `emitJpwabc(doc)` / `writeJpwabc(src)` | `src/model/tojpw.ts` `.jpwabc` 写出端：只经输入接口读谱，`emitJpwabc` 按形状拼输入（MusicXML 形状同 `jianpuInputOfXml`、简谱形状同 `jianpuInputOfDoc` 的口径） |
| `toPuText` | `src/omr/topu.ts`（唯一的「模型 → 文本谱」方向） |
| `export_pdf_cmd` | `src-tauri/src/lib.rs` 桌面端原生 PDF（`svg2pdf` + `usvg` + `lopdf` 合页） |
| `writePdf` | `scripts/pdfwrite.mjs`（成书路，**全仓唯一写 PDF 的地方**） |

## 关键判据

- **跨格式另存为要先问**：换的是源格式本身，目标装不下的东西会永久丢。
  `planSave` 算清单、`showConfirmDialog` 列出来、确认了才写。
  **存回原格式不问**——那是原文进原文出，不会丢。
- **PPTX 取展开档**那一套（`export.ts::pptxPainter`），哪怕屏幕正停在原样档。
- **PPTX 有一层字体度量修正**（`TARGET_ADVANCE`/`TARGET_DESCENT`）：排版是拿浏览器里的 PingFang SC
  量的，而 .pptx 里写的是 Microsoft YaHei（投影机与 Windows 上真正会用的那份）。
  两套字的 descent（0.357 vs 0.2617 em）与数字宽（PingFang 的「1」只有 0.401 em，YaHei 等宽 0.5864 em）
  都不同，不修正则文字整体下沉一格、「1」的八度点与减时线明显偏左偏短。
  做法：**按目标字体的 descent 定文本框底、把音符数字居中到目标宽度的框里**（框心落在 `JpNumber.cx`）。
- **歌词收尾标点并进前一个字并换半角形**（`TRAIL_PUNCT`）——YaHei 的全角逗号墨迹在字身正中，
  单独成框会顶到下一个字。
- 倚音底缘按目标字体的墨迹顶对齐（`jpLegacyDigitInkTop`）。
- 背景色白底一律不铺；非白则 PNG 铺画布底、混排 PDF 插满幅 rect、PPTX 写 `<p:bg>`。
- `.jpwabc` 只支持单声部，多声部时只导第一声部并 `setStatus` 提示。
- MusicXML **只有一份写出端**（`model/toxml.ts`，判据全录见 [../实现/MusicXML-导出.md](../实现/MusicXML-导出.md)）。
  **`.musicxml` 文档**里存的就是 XML，没改过存回原文、改过的已整份重写（`Measure.raw` 保证不丢）；
  **识别核对**（123 转换文本 + 识别底本）没改过给底本，改过整份重写。不再有增量 patch。

## 回归

```bash
node scripts/pptx-ref-check.mjs   # 拆开导出的 .pptx 量几何，与 2019 成品 ppt500 同判据
node scripts/pptx-check.mjs       # 两档版面
node scripts/pptx-export.mjs      # 500 首批量导出
node scripts/xml-roundtrip.mjs
node scripts/omr-export-check.mjs
HYMN500=<500首语料根> node scripts/musicxml-open-check.mjs
```

## 已知限制

- 没有 ABC 导出
- MusicXML：skip/limit 不表达、承接前音的增时线按普通音符写、多声部只保 `parts[0]` 往返

# 可视化编辑（`editor/visual/`）

## 职责

在谱面上直接选中、插入、修改音符与记号；操作说明在帮助的「可视化编辑」页（快捷键表由动作表生成）。
地基是[编辑器](编辑器.md)的**双向定位**（`editor/sync.ts`）：选中什么、改哪一段原文，一律按 `SyncEntry` 认。

## 入口

| 文件 | 作用 |
|---|---|
| `keys.ts` | **动作表**：快捷键、名字、说明只写这一份；键盘、帮助、右键菜单、记号面板都从它取 |
| `controller.ts` | `VisualEditController`：谱面焦点下的键盘、点击、右键；经宿主接口 `VisualHost` 向 App 要能力 |
| `cursor.ts` / `overlay.ts` | 两种光标在代码区 / 谱面的画法；换行符号、拍数不对的小节标红（叠加层，不重排版） |
| `ops.ts` / `breaks.ts` | 动作 → 对原文的局部补丁（与格式无关）；换行增删连带拆并歌词行 |
| `dialect.ts` + `dialects/` | **因格式而异的全在这里**（`FormatAdapter.editDialect`）：123、ABC、`.jpwabc`、文本谱各一份 |
| `menu.ts` / `preview.ts` | 右键菜单与记号面板；按键即发声 |

## 关键判据

- **源码仍是真身**：每个动作落成对代码区原文的局部补丁（`userEvent: "input.visual"`），不走「改模型再整份重出」
  （那样会丢注释与手写排版）。撤销重做就是代码区那份 history；补丁后立即重排（`reloadNow`），不等 200ms 防抖。
- **光标状态只存一份**：代码区选区。非空 = 编辑模式（方块），空 = 插入模式（竖线）；谱面光标由它推出，两侧不会不同步。
  代码区有焦点时原生选区就是这两种样子；谱面有焦点时代码区另画（`cursor.ts`）。**没有第三种状态**——
  文字的「选中」与「编辑」之分靠**焦点在谱面还是在代码区**（`document.activeElement === scorePane`），不另立状态机。
- **选中音符只罩音头**（升降号、唱名、八度点），不带减时线、附点、增时线与 `.jpwabc` token 里的括号（`EditDialect.noteParts`）；
  动作认音符按「选区碰到的」，所以只罩音头照样能改整个 token。
- **文字是单击选中、双击才编辑**（Sibelius 那一路的手感）：单击歌词字或页眉字段（标题/副标题/署名/调号拍号）
  只选中它整段原文、焦点留在谱面（此时 `Delete` / `Backspace` 删掉这段文字）；双击才进插入模式——
  光标落在原文里点中的那个字前后（`getExtentOfChar` 按字的中线分，画出来的字与原文按包含关系对位：署名会补「作词：」、`{三四}` 画出来不带括号），
  焦点交给代码区，接着打字就是改原文（谱面焦点下数字键是插音符，不能留在谱面上）。
  双击靠浏览器原生的 `click` ×2 + `dblclick` 顺序：第一下已经选中，`dblclick` 再覆盖成插入光标，**不自己做点击计时**。
- **歌词一次只选一段里的一个字**：展开档的音符格把各段歌词收在同一个 `<g>` 里，点选按段号（`Lyric.verse` ↔ `SyncEntry.verseNo`）取那一段自己的字；
  点亮音符时格里的歌词标 `cursor-off`、不上光标色。`.jpwabc` 的 `.Words` 逐字记原文位置（`WordsItem.source` → 模型 `Lyric.source`），所以也能单点一个字。
- **页眉字段**：模型不记原文位置，按格式从原文认（`EditDialect.headerFields`，`visual/header.ts`：123/ABC 的 `T:`/`C:`/`K:`/`M:`，
  文本谱的 `T:`/`Z:`/`1=C4/4`…，`.jpwabc` 的 `.Title` 段），并进索引（`SyncIndex.addHeader`，条目 `header`）；
  谱面上两个排版器把页眉文字标 `hdr`、调号 `hdr-keysig`、拍号 `hdr-time`（`headerPartsOf`），文字按字对、调号拍号按角色对（`App._bindHeader`）。
- 选中色只有一种（蓝）：光标所在、点选、编辑方块、代码区选区与光标同色；拍数不对的红框要接 hover 说明，点击透过它落到音符上（`hitThroughOverlay`），
  且与上次一样时不重画（焦点一进谱面就会重画叠加层，换掉按下时点中的节点会丢掉这一下点击）。
- 动作之前先看索引是否按当前原文建的（`syncFresh`）：刚撤销、刚在代码区打过字、重排还在防抖里时先重排，否则会按旧偏移改错地方。
- token 读不懂（夹着别的东西，如文本谱 `5&rit/`）就拒绝并说明，不硬改。
- `/` 不绑定：留给歌词对位（歌词录入模式，见 [待办](../待办.md)）。
- 只在简谱两档启用；五线谱/混排不开放编辑（同统一 ScorePainter 设计的约定）。
- **试听播放 / 暂停中点音符让给播放**：点中音符（音头、歌词、增时线）只跳到那儿接着播，不进点选（`App._seekByPick` / `_onSyncClick`）。
  否则点击先被点选接走，时间不动、音符反倒被选中；停止状态下照常点选。

## 点得中「自己」：五种身份五种认法

音符之外还有几样能单独点选的东西。它们在模型里的身份**各不相同**（同样是增时线，`.jpwabc` 与 123 就是两种），
所以认它们的办法也各走一路——下次再加一样，照这张表对号入座：

| 东西 | 模型里是什么 | 谱面上怎么认 |
|---|---|---|
| **增时线**（123 / 文本谱：独立的 `-`） | 有自己的 `ElementId`（`Chord.sustains[]` 各带一个） | 最省事：原样文档按它自己的 id 收进 `noteItems`；简谱引擎的输入把它压成计数（`JChord.beats`）不带 id，但排版时每条各是一个音符格、按树序跟在音符格后面，于是**按序号数**（`SyncEntry.ord`） |
| **增时线**（`.jpwabc`：写在 token 里的 `5---`） | **模型里没有它**——`-` 是音符 token 的一部分，`Chord.sustains[]` 是空的，索引里也没有 `sustain` 条目 | 谱面上照样一条一格（都是同一个和弦 id 的音符格）。这几格在 `_buildSync` 的**第二趟**兜底指向宿主音符（第一趟要先让 123 / 文本谱那种有自己条目的格认领自己），点中第几格就选 token 里第几个 `-`（`NoteParts.sustains`），`Delete` 走 `dropInlineSustain` 只短一拍 |
| **小节线** | **没有 id**（`model/doc.ts` 的 `Barline` 只有样式与 `source`，`slots.ts` 给它的 ref 也不带 id） | 借挨着的那个音符的 id + 哪一侧（`SyncEntry.edge`、`Barline.ownerEdge`），口径与 `sync.ts::addPartExtras` 一致。简谱引擎在 `buildChordIndex` 那趟遍历里按前后顺序认（树序 = 读谱顺序，跨小节跨行跨页都对）；原样文档在 `paintVoice` 的线性循环里认 |
| **圆滑线 / 延音线** | 跨元素的**一对端点**（`Mark.start` / `end`，两段原文 `openSource` / `closeSource`） | 按 `${起点 id}:${终点 id}` 认（`Tie.startId`、原样文档的 `slurItems`）。`(` 与 `)` 两条 `SyncEntry` 指向同一条弧，删除时两个括号一起删（`spansToDelete` 认 `pair`） |
| **减时线** | **不是对象**（时值的派生量，见 [模型-scoredoc](模型-scoredoc.md) 的「派生量不存进 `ScoreDoc`」） | 不建索引：照附点那套**按几何命中**（`beamAtPoint`，量音头那个数字的下缘往下一条带），选中的是 token 里那串符号（`NoteParts.beams`，123/`.jpwabc` 是 `_`、文本谱是 `/`；ABC 的时值是数字，没有单独符号可选，为 null） |

几条**别再想一遍**的取舍：

- **不给小节线发独立 `ElementId`**：要动 `IdGen` 分配、五种格式的往返与 `SourceSpan` 填充，代价远超收益。
- **不给减时线打类名**：两个引擎里它各是 `BeamLine` 与 `voice.underlines` 的一排 `rect`，打类会改 SVG 输出、
  `jianpu-svg-dump` 整片要重新定基线。
- **点 token 里的东西一律「选 token 里的一段」**：附点、减时线、`.jpwabc` 的增时线都没有独立对象，
  选中的都是原文 token 里的那几个字符，删除也都经方言的 `parseNote`/`printNote` 改 token，不做裸文本删除。
  这几支在 `handleClick` 里**都要排在音符分支之前**——音符分支先返回就轮不到它们了。
- **细线的命中放宽放在控制器侧**（`thinAtPoint`，照 `dotAtPoint` 用 `getBoundingClientRect` + pad）：
  竖线的几何包围盒宽是 0、横线高是 0，往页面树里塞透明的加宽命中条同样会动谱面指纹，不值当。
  选中框同理——按长边比例撑到看得见（`plump`）。
- **多声部谱里贯穿几个声部的小节线只画一根**（`paintVoice` 被 `skipBarlines` 跳过、另在成组那段画），
  所以各声部在这一处的小节线条目**都指到这同一根**上（按横坐标对）。
- 跨行的弧另一端不在本行时本来就画不全（[待办](../待办.md) R5），点不中的那部分照现状。

**一条链上的东西改一处就要看全链**：模型 → `sync.ts` 的条目（`edge` / `ord` / `own`）→ 两个排版器的索引
（`ScorePainter.barlineItem` / `slurItem` / `chordItem`、原样文档的 `barlineItems` / `slurItems` / `noteItems`）
→ `VisualHost.barlineEl` / `sustainEl` / `slurEl` → 控制器的 `ownEl` / `boxOf`。
断了哪一环都不会报错，只会「选中了但框画在旁边音符上」——跑起来才看得见。

## 各格式的要点

- **123**：`$` 结束一行曲，其后的 `w:` 只挂最后一行曲——插换行要把代码行拆开、每条 `w:` 按对位格数（`parseLyricLine` 的 `starts`）拆两半；删换行反过来接上，前一行词不够长用 `/` 补格。`+:` 续行拆不清，拒绝。
- **ABC**：音名 ↔ 唱名按调号换算（八度口径同 `degreeFromPitch`），时值相对 `L:`，升降号是绝对的（原样保留），延音线写 `-`，换行就是代码行末（`w:` 对紧挨在前的代码行）。
- **`.jpwabc`**：增时线与弧括号在音符 token 里；`-` 不能与 `_`、`.` 连写（`validate` 挡住）；歌词按 `@小节,音符` 锚定、小节中间的 `$` 也算新小节，所以改完按「锚住的音符在原文的位置 → 映射到新原文 → 重数坐标」重算锚点（`postEdit`，与改动并成一步撤销）。
- **文本谱**：升降号后置、八度点按方言（番茄 `'` `,`、诗歌本 `g` `d`）；换行不是符号，增删换行 = 照现有行结构加减一刀，复用乐句重排的原文搬运重切 `Q:`/`C:` 行（`pu/phrase.ts::puLinesEdited`、`pu/relayout.ts::relayoutPuBreak`）；弧的 `)` 按队列配对，不许嵌套交叠。

## 小节时值自检（`model/beatcheck.ts`）

逐小节按拍号查时值（四分音符 = 1 拍，按 `divisions` 算——`<type>` 不含增时线），
混合拍（`Song.extraTimes` / 识别的 `meters`）对上任一即过；放过弱起首小节、首尾相加一小节、相邻两个不满相加一小节（反复记号劈开的）、
MusicXML 的 `implicit`；无拍号不查。**弱起由调用方认**（`opts.pickup`）：识别一律认；编辑器只认**打开时**首小节就不满的声部
（`VisualEditController.documentLoaded` 后第一次查时定下），改谱把原本满的首小节删短了照样报。
**空小节另从原文认**：删掉占满一小节的音（`5 - - -`、`5---`）原文剩 `| |`，解析时空小节不成小节、自检看不见，
编辑器按「同一曲谱行里两条小节线之间只有空白」认出来一并标红、计数，点计数把插入光标放进去。
每次重排都重查（谱面上改、代码区里打字都算）。编辑器标红 + 代码区波浪线；简谱识别完在核对视图按源图坐标标出（`omr/beats.ts`），
私有仓库的 `beat-check.mjs` 也经 CLI 调同一份。

## 回归

回归脚本、语料与基线不在本仓库（本地私有仓库）。可视化编辑有一份专门的（四种格式逐动作断言原文逐字、选区吸附、撤销还原，
另验点选音头 / 附点 / 小节线 / 增时线（独立的与 token 里的两种）/ 弧 / 减时线、文字单击选中与双击进编辑、
记号删除、帮助快捷键表、小节时值自检、右键菜单、按键发声）。

## 已知限制

- 跨行的圆滑线点不中另一行那半（[待办](../待办.md) R5）。
- 小节线只能选中与删除，还不能在谱面上改样式（双线、反复、终止）。

# 排版：成书（诗歌集）

**判据全录** → [../实现/矢量PDF识别.md](../实现/矢量PDF识别.md)（2438 行，含整条成书重排 B 路）

## 职责

500 首级整本诗歌集的版面：装箱分页、目录索引、页眉页码、注解框、书级样式。
**目前是脚本级（CLI），编辑器未接**——这是重构路线 **R3**。

## 入口

| 文件 | 作用 |
|---|---|
| `src/pdflayout/spec.ts` | 一页的结构化版面规格：`PageSpec` / `SongPlacement` / `StoryBox` / `TextRun` / `PageKind` |
| `src/pdflayout/bookmeta.ts` | 书级内容：`BookMeta` / `KeyMeter` / `SectionWord` / `Annotation` / `RuleFrame` / `TocRow` / `IndexRow` / `FrontPage` / `PageLabel` |
| `src/pdflayout/bookparts.ts` | 书级内容排回页面：目录、索引、注解块、扉页、页框 |
| `src/pdflayout/bookstyle.ts` | **书籍样式** `BookStyle`（见 [../样式机制.md](../样式机制.md)） |
| `src/pdflayout/stats.ts` | 从原书版面统计出 `BookStyle`（取**中位数**） |
| `src/pdflayout/drawlist.ts` | **两条重排路与 PDF 输出之间的唯一契约**：`DrawText`/`DrawPath`/`DrawRect`/`DrawLine`/`DrawPage`/`DrawBook` |
| `src/style/books/hymn500.jpcss` | **歌本模板**：曲号/标题/调号拍号/署名、页眉页码的位置与格式（`rebuild.mjs --template=` 可换），排版在 `style/template.ts`，`key-meter()` 组件在 `pdflayout/booktemplate.ts` |

## 两条重排路

| 路 | 脚本 | 位置从哪来 | 样式从哪来 |
|---|---|---|---|
| **A 文字原位替换** | `relayout.mjs --mode=text` | 原件 `PageSpec` | `BookStyle` |
| **B 从数据重排** | `rebuild.mjs` | 排版引擎算 | `BookStyle` |

`BookStyle` 是两条路**唯一共享的东西**。写 PDF 一律走 `scripts/pdfwrite.mjs`（**全仓唯一写 PDF 的地方**）。

## 关键判据

- 装箱：短曲**半页起排**接在上一首下面；**一首歌不跨同一张纸的正反面**。
- `rebuild` 的排版口径：谱面全走排版引擎，整本那一层只管**书级装饰**。
- 纸顶那一块照 500 首重排排：标题居中、**调号拍号在左**（升降号提到音名之前、小一号并抬高）、
  词曲署名右对齐逐行，调号拍号基线与最后一行署名齐。
- 注解正文存**行距比例**而非绝对行距——原书每框字号都不同（按剩余空间缩排）。
- 「一行几句」走成书那套模式阶梯（B 每 2 句一行 → A 一句一行 → C 均匀）。
- **改弧高这类常量会牵动全书断句**（弧高 → 行高 → 每页行数 → 重排），动完必跑 `rebuild` + `line-check`。
- `browser.ts` 里几个**手调常量**的默认值必须写在代码里——歌本样式表的实测部分（`hymn500-measured.jpcss`）是 `stats.ts` 生成的，重跑就丢。
- **样式只来自 `.jpcss`**：`hymn500-measured.jpcss`（统计生成）+ `hymn500.jpcss`（模板与手调）按序叠，
  `node-harness.mjs::loadBookStyle` 读成 `BookStyle`（`style/bookjpcss.ts`）；`rebuild` / `relayout` / `line-check` 等都走它，没有 json。

## 已知限制

- **编辑器无入口**（R3）；`vector.ts::isVectorPdf` 至今无调用方
- `line-check` 两条定点断言不过、全书基线 D5 0→1、V5 0→3（改动前就有）：
  V5 是房号原文带逗号，D5 是 446 断句 3 行→6 行。**先定房号原文的规范**
- 和弦剩 4.5% 差异、调号剩 17 首（多为原书重排时转过调，不是读错）
- 反复与房号**只记录、不计进内容差异**（识别侧只有几何，判据太粗）

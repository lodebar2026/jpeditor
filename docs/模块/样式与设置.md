# 样式与设置

**机制与判据** → [../样式机制.md](../样式机制.md)

## 职责

排版参数、主题、用户设置的存取与应用。**一份样式表（`src/style/`）经适配器灌进四把尺子。**

## 入口

| 件 | 位置 | 作用 |

## 关键判据

- **主题由排版模式决定**：展开 → projection、原样 → print。展开档的字号、比例、配色两种格式共用（规则不带限定）；
  原样档的纸与字号 `.jpwabc` 与文本谱各记各的（`engine` 限定），配色共用。
- **设置面板只摆当前模式下真正生效的项**（`editor/dialogs.ts::showOptionsDialog`）：
  字号与前景色只有简谱/文本谱排版器吃（混排用 MusicXML 自己那套）；「每页行数」只归展开档。
- **没摆出来的项一律不回灌**——把控件初值当用户输入送回 `applyRenderSettings`，
  等于替用户做了他没做过的决定。
- 「恢复本档默认」清当前主题的用户层，另一档不动。
- **背景色是唯一四档通吃的**：它铺的是**纸**不是谱（灌成 `--score-page-bg`，由页元素继承；
  导出时 PNG 铺画布底、混排 PDF 插满幅 rect、PPTX 写 `<p:bg>`，白底一律不铺）。
- 文本谱的字号面板给的是 **pt**，由 `layout/original/compose.ts::resolveScale` 换算成**整体缩放**；纸与页边距不跟着缩；填 0 = 跟随版式量到的原尺寸。
- `LayoutOptions` 的约定：**0 = 引擎自算**；`applyFontSize()` 一处算出所有随字号的间距。
- 文档内样式：文本谱的 `FontSize:`/`Margin:` 先生效，面板那层叠最外。`.jpwabc` 只能写 `.Layout`
  的 `LinesPerPage`/`BreakPoints`（`.Fonts`/`.Options` 段内容被丢弃）。
- 旧版散存的 `fontSize` / `jpPaper` / `expandedColor` 等字段**不读**（未做存量迁移）。
- **诗集样式表**（歌本 `.ss`）在级联里排在内置主题之后、曲内层之前。打开文件时按序找，先找到的生效：
  ① 123/ABC 的 `I:style 相对路径`（相对谱文件所在目录）→ ② 设置里给这个目录（或祖先目录）手动选过的（选「不用」记空值，屏蔽自动发现）
  → ③ 自动：谱文件所在目录往上最多 3 级、到家目录为止，每级看本级与 `样式/`、`style/` 子目录；同级多份挑与目录同名的 → `book.ss` → 文件名排序第一个。
  歌本按「`<歌本>/歌谱/曲.jpg`」放时，`<歌本>/` 下放一份就管住整本。浏览器版读不了目录，只有手动选（存原文）。
- **编辑器只取样式表里各尺子口径一致的部分**：角色的字体（族、字重、`@font-face`）、页眉四项的字号、纸与方向、配色；
  间距覆写、模板、成书块不用——成书是 pt、五线谱是 tenths，整份照搬会把混排的简谱数字缩成一点。
- **页眉四项各档共用一份**：用户层单独一层 `_userLayers.header`（不带限定），叠在各档用户层之上；
  「恢复本档默认」不清它。没设的项各排版器用自己的出厂值（简谱引擎借歌词字体、原样文档布局 `JianpuMetrics.font.text`、
  五线谱 credit 自带的或 20/11pt）。展开档原来单列的标题 / 词曲字号并进了这一组。
- **打开 MusicXML 自动跟随谱里的页眉字体**：`<credit-words font-family/font-size/font-weight>` 按 `credit-type`
  归到四项（没写类型的按版面：最大号且不靠右的是标题、靠右的是词曲），作曲内层；面板显示「跟随文件（魏碑）」。
  **展开档只跟族不跟字号**——印刷纸上的字号搬到 960×540 的投影片上太小。
  MusicXML 转 123/ABC 时写成 `I:meta font-title 16 Weibei SC`（`font-subtitle` / `font-scripture` / `font-credit`，
  「字号 [bold] 字体族」，`model/pagemeta.ts`），打开照样跟随；转 JPWABC/文本谱记进页眉用户层（`App._carryHeaderFonts`）：
  族不带限定，字号只记 `mode: original` 与 `mode: staff` 两条（展开档仍是投影片字号）；面板改某项字号时连这两条一起清。
- 题下经文（`Song.meta.scripture` + `scripture-ref`）三档都画：简谱引擎排在副标题下（`jianpupages.ts`）、
  文本谱原样接在标题行下（`compose.ts::titleLines`，避让同一份落位）、五线谱自动铺排的页眉排在副标题下（`layoutpass.ts::autoLayoutHeader`）。
  `.jpwabc` 与文本谱没有这个字段。
- **纸张三档各记各的**：简谱原样（print·jianpu）、文本谱原样（print·pu）、五线谱/混排（staff，出厂 A4）；展开档只有投影片比例。
  每档是「纸 + 方向 + 四边距（mm，留空 = 排版器自己的缺省）」。
- **谱里写了纸就跟随文件**：MusicXML 的 `<page-layout>`、123/ABC 的 `I:meta page …` 作为曲内层垫在用户层之下，
  面板显示「跟随文件（A5 横）」。用户在这一档**明确选过纸就整层不用**文件的纸与边距（`App._userSetsPaper`）；
  选回「跟随文件」清掉用户层的纸、方向、边距。面板里没动过纸张栏就不写用户层，免得把「跟随文件」钉成具体的纸。
- **五线谱/混排的「基础字号」是两项**：谱表大小（mm，五条线的总高，即 MusicXML `<scaling>` 的 40 tenths）与歌词字号（pt），
  记在 staff 用户层的 `staff.size` / `staff.lyricSize`，留空跟随文件（没写是出厂 7mm / 约 9.9pt）。
  **只有用户明确设了才动引擎**（`MixedOptions.staffSizeMm` / `lyricPt`）：换谱表大小时纸与边距的 pt 不变、tenths 按新比例换算，
  谱里的版面坐标不再用（整份自动铺排）。MusicXML 转 123/ABC 时写 `I:meta staff-size` / `lyric-size`（`model/pagemeta.ts`），
  转 JPWABC/文本谱记进设置——否则转完按出厂 7mm 排，字相对音符小一圈（原谱常见 5.29mm / 10pt）。
- 五线谱/混排换了纸（`MixedOptions.page.override`）：谱里按原纸算好的版面坐标对不上了，整份按新纸自动铺排。
- MusicXML 转成 123/ABC 时纸写成 `I:meta page …`（`model/convert.ts` 经 `withPageMeta`），写回 MusicXML 再还原成
  `<page-layout>`（`xmlproject.ts`）；转成 `.jpwabc`/文本谱装不下，丢失清单里列「纸张」，并把那张纸记进对应档与五线谱档的用户层。

## 已知限制

- 歌本 `.ss` 只管全书版式，不做逐曲规则（逐曲修改走数据，见 [../样式机制.md](../样式机制.md) §11）；页位限定没有消费者；「校对对照」主题不在样式层
- 面板只暴露字号 / 纸 / 配色，`overrides` 没有界面
- 文本谱的 `Space:` / `Off:` 已解析但语义未实现

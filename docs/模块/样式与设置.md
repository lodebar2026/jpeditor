# 样式与设置

**收敛方案** → [../样式机制.md](../样式机制.md)（类 CSS 设计）

## 职责

排版参数、档位 profile、用户设置的存取与应用。**现状是三套尺子 + 一层用户设置。**

## 四层

| 层 | 位置 | 从哪来 | 作用域 |
|---|---|---|---|
| `LayoutOptions`（约 140 项） | `src/layout/options.ts:8` | 手调 + 从 2019 年成品 .pptx 量回 | `.jpwabc` / 展开档 |
| `PuMetrics` | `src/pu/metrics.ts:20` | 对原版渲染逐项实测 | 文本谱原样档 |
| `BookStyle` | `src/pdflayout/bookstyle.ts:319` | `stats.ts` 统计原书中位数 | 成书 |
| `PersistedSettings` | `src/editor/settings.ts:16` | 用户面板，localStorage | 运行时 |

两个「样式表应用器」（契约：**painter 构造之后、`resize` 之前调**）：
`layout/pptxstyle.ts::applyPptxStyle`（展开档笔画）、`pdflayout/browser.ts::applyBookStyle`（成书）。

## 关键判据

- **设置面板只摆当前模式下真正生效的项**（`editor/dialogs.ts::showOptionsDialog`）：
  字号与前景色只有简谱/文本谱排版器吃（混排用 MusicXML 自己那套）；纸张与字号两档各记各的；
  「每页行数」只归展开档。
- **没摆出来的项一律不回灌**——把控件初值当用户输入送回 `applyRenderSettings`，
  等于替用户做了他没做过的决定。
- **背景色是唯一四档通吃的**：它铺的是**纸**不是谱（灌成 `--score-page-bg`，由页元素继承；
  导出时 PNG 铺画布底、混排 PDF 插满幅 rect、PPTX 写 `<p:bg>`，白底一律不铺）。
- 文本谱的字号面板给的是 **pt**，但它整套尺寸是实测来的、不由一个基础字号派生，
  所以 `PuPainter.resolveScale` 换算成**整体缩放**（分母由 `digitFontSizeOf` 从 `digitInkHeight` 反推）。
  纸与页边距不跟着缩；填 0 = 跟随版式量到的原尺寸。
- `LayoutOptions` 的约定：**0 = 引擎自算**；`applyFontSize()` 一处算出所有随字号的间距。
- 单位约定：随字号缩放的量存 **em**（基准 = 音符字高），线宽/点径/纸张/页边距存 **pt**。
- 文档内样式：文本谱的 `FontSize:`/`Margin:` 先生效，面板那层叠最外。`.jpwabc` 只能写 `.Layout`
  的 `LinesPerPage`/`BreakPoints`（`.Fonts`/`.Options` 段内容被丢弃）。
- `settings.ts` **只管存取不管应用**。

- 文本谱的 `Space:` / `Off:` 已解析但语义未实现

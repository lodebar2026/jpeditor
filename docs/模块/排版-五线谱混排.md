# 排版：五线谱与混排

**判据全录** → [../实现/混排.md](../实现/混排.md)

## 职责

MusicXML → 五线谱排版；可叠加简谱层成「混排谱」。移植自 C++ musicpp，单位 tenths。

## 入口

| 函数/类 | 文件 | 作用 |
|---|---|---|
| `layoutStaff(doc, options)` | `src/mixed/layout.ts` | `ScoreDoc`（MusicXML 形状）→ `StaffLayout`（版面态） |
| `finishMixedScore(score, …)` | `src/mixed/layoutpass.ts` | 各声部读完后的系统/分页/谱表间距/自动版面 |
| `drawJianpuOverlay` | `src/mixed/jianpuoverlay.ts` | 简谱叠层（逐音成柱；唱名/临时记号/减时线/取声部来自语义层） |
| `StaffLayout` 与版面节点 | `src/mixed/model.ts` | 五线谱引擎的版面态（**不是模型**：语义经各节点 `src` 从 `ScoreDoc` 取） |
| `formatMixedScore(score)` | `src/mixed/painter.ts:30` | 排版 |
| `MixedPainter` | `src/mixed/painter.ts:237` | 实现 `PagePainter` |
| `drawSystem` / `drawNotesNormal` / `drawBeams` / `drawLrc` / `drawHarmony` | `src/mixed/render.ts` | 绘制 |
| `mixedVisitor` | `src/mixed/painter.ts:320` | 页面树 → SVG（与谱面那路语义不同） |

## 吃什么吐什么

```
MusicXML → ScoreDoc（fromxml）→ StaffLayout（layoutStaff）→ 页面树（五线谱层 render.ts + 简谱叠层 jianpuoverlay.ts）→ mixedVisitor → SVG
```

`五线谱` 与 `混排` 是同一个排版器的两种状态，差别只在要不要叠简谱层（`mixedShowJianpuLayer`）。

## 关键判据

- `mixedVisitor` 把 matrix 加在**叶子**上、线与文字写死 black、只递归 Group；
  谱面那路的 `svgVisitor` 每个 item 都产生 `<g>`、颜色取 item、无条件递归。
  **两者的差别不许收进 `walkPageItem` 骨架**，理由写在两个 visitor 的注释里。
- 简谱层的纵向阶梯与谱面同口径（`jpStackGap` / `jpBelowGap`）。
- 拍号的竖向只认拍值字号——混排字号是 0.75 H，按谱面档（0.5625 H）反算的常量在这里会挤成一团。
- 混排视图的纸宽也取全仓那一份 `--score-page-max`（从前单独写 620px，同一首歌切过来纸就窄三分之一）。

## 回归

```bash
node scripts/shot.mjs            # 切到混排视图截图
node scripts/zoom-check.mjs      # 四档纸宽一致
node scripts/staff-ui-check.mjs  # 喂一页五线谱 PDF，看是否进混排视图并铺出页
```

## 已知限制

- 简谱路径同样**丢弃跨谱行的连音**（musicpp 原实现亦如此）
- 设置面板的字号/前景色不作用于混排（它用 MusicXML 自己那套）

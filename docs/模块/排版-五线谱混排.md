# 排版：五线谱与混排

**判据全录** → [../实现/混排.md](../实现/混排.md)

## 职责

MusicXML → 五线谱排版；可叠加简谱层成「混排谱」。移植自 C++ musicpp，单位 tenths。

## 入口

| 函数/类 | 文件 | 作用 |
|---|---|---|
| `layoutStaff(doc, options)` | `src/mixed/layout.ts` | `ScoreDoc`（MusicXML 形状）→ `StaffLayout`（版面态） |
| `finishMixedScore(score, …)` | `src/mixed/layoutpass.ts` | 各声部读完后的系统/分页/谱表间距/自动版面 |
| `drawJianpuOverlay` | `src/mixed/jianpuoverlay.ts` | 简谱叠层（逐音成柱；唱名/临时记号/减时线/取声部来自语义层） |
| `StaffLayout` 与版面节点 | `src/mixed/model.ts` | 五线谱引擎的版面态（**不是模型**：语义经各节点 `src` 从 `ScoreDoc` 取） |
| `formatMixedScore(score)` | `src/mixed/painter.ts:30` | 排版 |
| `MixedPainter` | `src/mixed/painter.ts:237` | 实现 `PagePainter` |
| `drawSystem` / `drawNotesNormal` / `drawBeams` / `drawLrc` / `drawHarmony` | `src/mixed/render.ts` | 绘制 |

| `layoutMixedSongbook` | `src/pdflayout/songbook.ts` | **混排歌本**：书清单 + 歌本 `.jpcss` → 整本 DrawPage（逐曲标题块/页脚块、帧流式装页、目录），移植原排版程序 `genSongBook` |
| `kl2020-prep.mjs` | `scripts/` | 歌本逐曲改谱：原排版程序 `fixPaoScore` 的修改写进 MusicXML 修订副本 `.fixed.xml`（小音符、段号、符干、文字换行、`relative-x/y`、歌词字体、和弦上方音画小） |

## 吃什么吐什么

```
MusicXML → ScoreDoc（fromxml）→ StaffLayout（layoutStaff）→ 页面树（五线谱层 render.ts + 简谱叠层 jianpuoverlay.ts）→ mixedVisitor → SVG
```

`五线谱` 与 `混排` 是同一个排版器的两种状态，差别只在要不要叠简谱层（`mixedShowJianpuLayer`）。

## 关键判据

- `mixedVisitor` 把 matrix 加在**叶子**上、线与文字写死 black、只递归 Group；
  谱面那路的 `svgVisitor` 每个 item 都产生 `<g>`、颜色取 item、无条件递归。
  **两者的差别不许收进 `walkPageItem` 骨架**，理由写在两个 visitor 的注释里。
- 简谱层的纵向阶梯与谱面同口径（`jpStackGap` / `jpBelowGap`）。
- 拍号的竖向只认拍值字号——混排字号是 0.75 H，按谱面档（0.5625 H）反算的常量在这里会挤成一团。
- 混排视图的纸宽也取全仓那一份 `--score-page-max`（从前单独写 620px，同一首歌切过来纸就窄三分之一）。
- **歌本**（`songbook.ts`）的几何以成品 PDF 为准，不以原程序的式子为准：标题块里经文的位置、行距与块高是按
  KL2020-1219 p2/p4/p17 量回的（原式算出来经文低 9.4pt、谱面低 18~23pt，见 `kl2020.jpcss` 的注释）；
  页脚块照原式（成品逐点对上）。字高按字号算（原程序 `Font::height()` 就是字号），ascent 取字体的。
- 混排读几项标准位置/样式属性：和弦 `relative-x`、文字 `relative-x/relative-y`、segno/coda `relative-x`、歌词 `<text>` 字体、
  和弦内单音 `<type size="cue">`（简谱层选旋律音时跳过 cue 音）、`<words>` 文字里的换行拆成多行。
- 歌本（`songbook.ts`）开 `textLineHeightBySize`：谱行包围盒里文字行高按字号算（原程序口径）。缺省按 ascent−descent（约 1.45 个字号），
  那样《我心等候祢》拆行后会挤成两页；编辑器混排视图不开（开了 568 份里 104 份版面会变）。
- 歌本出 PDF：混排里文字的角色就是字体族；CFF 轮廓的字体（思源黑体、Bravura）pdf-lib 子集化后不合规，走轮廓画。

## 回归

```bash
node scripts/shot.mjs            # 切到混排视图截图
node scripts/zoom-check.mjs      # 四档纸宽一致
node scripts/staff-ui-check.mjs  # 喂一页五线谱 PDF，看是否进混排视图并铺出页
node scripts/mixed-tree-dump.mjs --diff=<基线>  # 页面树逐页 SVG 指纹，改混排输入/画法必跑
node scripts/mixed-pixel-dump.mjs  # 逐像素对基线 PNG（带容差），改绘制次序/分组时用
node scripts/mixed-shots.mjs --root=<语料> --out=<输出>  # 整目录截图 + 总览页
node scripts/gen-manifest-kl2020.mjs                      # 曲目库 → testdata/kl2020/book.json
node scripts/kl2020-prep.mjs                              # 逐曲改谱 → .fixed.xml，清单指向副本
node scripts/kl2020-book.mjs --flow=new-page|continue --expect=testdata/kl2020/expected.json  # 出歌本并与成品目录逐首比起始页
```

## 已知限制

- 简谱路径同样**丢弃跨谱行的连音**（musicpp 原实现亦如此）
- 设置面板的字号/前景色不作用于混排（它用 MusicXML 自己那套）
- 歌本的 `features: hwid` 用半角标点替代（出 PDF 不做 GSUB）；歌词的 `lrcHWID` 仍未落地

# 简谱混排与独唱谱补认（位图五线谱识别）

> [位图五线谱识别](../位图五线谱识别.md)的分篇。2026-09-23 拿《是谁》（简线混排、600dpi PNG）
> 与《善牧恩慈歌》（铅字本 SATB 闭合谱、线距 11px 的扫描 JPG）两首新 GT 换来的判据；
> 同日续加《赞美一神》（SATB 闭合谱、谱表间印简谱行）。

## 简谱行：定位与认领（`jianpuband.ts`）

混排谱在每行五线谱正上方印一行简谱，再往上才是和弦字母。不挡的话，数字「0」「6」、
增时线「–」落在谱表上方一两格，被收成全休止、加线上的符头；和弦字母又被简谱行隔在
和弦带窗口（顶线上方 1.0~3.2 格）之外，《是谁》24 个一个没认。

- **判据是小节线对齐**：简谱行的小节线是悬在谱表上方的短竖线（1.2~3.5 格长，《是谁》2.34 格），
  与谱表小节线**同 x**（0.6 格内）。至少对上两条才算；独唱谱、合唱谱对不上，这一段空转。
- 带的范围：对上的那几条小节线上下各放 **0.8 / 0.3 格**——上面要罩住高音点和弧顶
  （弧顶比小节线顶高 0.7 格），下面放得少，因为往上的符杠离小节线下端只有 0.4 格。
- **只抹整块落在带里的连通块**（`eraseInBand`），同时抹原图与去谱线图、摘掉带里的原语。
  按矩形一刀切会把伸上来的符杠削掉。
- 抹之前把条切下来（`jianpuStrips`），和弦带对这行谱改贴在简谱带上沿之上 3 格（`ceiling`）。

## 简谱互证（`jianpufuse.ts`）

简谱行离线送简谱那条路（`recognizeJianpu`，要 OCR，所以走缓存：
`gen-rasterjianpu.mjs` → `rasterjianpu.json`，按条内容指纹寻址）。《是谁》五行只有一处读错
（首小节第一个 `0` 读成 `1`），五线谱那边则有 G4 读成 E5、附点全漏、符头漏检。

- **配对**：简谱数字印在对应符头的正上方，但整页有系统性平移（《是谁》半格上下）——
  先取「每个数字到最近符头的 x 差」的中位数，扣掉后 **0.8 格**内一对一贪心配。
  `StaffNote.x` 是符号盒左缘，要换成符头中心。休止与音符也配（`0`/`1` 最容易读混，
  配上了才不会被当成「没配上的简谱音」去补），这种对什么也不改。
- **八度**：简谱只给相对八度，`1` 的绝对位置由全页配上的对投票（取众数）。
- **只拿拍数自洽的简谱小节纠**（小节和等于全页众数）。
  - 音高：配上的音照简谱改（只差八度的保留发声升降，换了音名的按调号重算）。
  - 时值：只在五线谱这一小节**不自洽**时改，而且只改音符对音符的（休止在简谱里按拍拆开写）。
  - **配上的音同一和弦里的其余音删掉**——简谱是单旋律。这是五线谱那边最常见的错：
    符干另一头被当成符头（G4 的符干顶上多个 E5），与真头拼成和弦，写出时还排在前面。
  - 五线谱超拍、没配上的音删掉正好补平才删；缺拍、没配上的简谱音正好补平缺口才补
    （照最近的已配对音抄一份，改音高时值 x，不挂和弦组，小节退回按顺序写）。
  - 删音时**把歌词过继**给留下来的音：挂词在互证之前，字常挂在假音上（「從」「認」就这么丢过）。

《是谁》：音符 88.5% → **100%**、和弦 0 → **100%**、歌词 94.8% → 98.1%。

## 独唱谱/合唱谱通用的补认（这两首暴露、全语料受益）

| 条目 | 位置 | 病例 | 判据 |
|---|---|---|---|
| 拍号合理性 | `recognize.ts` 拍号自举 | 铅字本「4」过不了 `timeSig4` 宽度闸，却以 141/166 过了 `timeSig1`，整首 1/1 | 分子至少为 2 |
| 拍号兜底 | 同上，页末 | 拒掉之后没有 `<time>` | 全页没拍号时按第一声部小节和推 n/4；4 拍不少于最多那档的八成就写 4/4，别的要压过第二名 1.5 倍 |
| 调号兜底 | 同上 | 铅字本细长升号到模板 130 > 90，调号整个丢，测评按「移调」把整首平移、善牧音符只剩 22% | 谱号右边 1.5 格内一串、宽不过高的一半、高 1.8~3.4 格，模板距离放到拍号那档（180）；噪点跳过不断串 |
| 二分休止 | `restKind` | 扁矩形休止一律记整小节休止 | 中心在第二线与中线哪一半：下半是 `restHalf` |
| 符杠截段不是休止 | `besideStem` | 八分音符对的短符杠斜穿谱线，夹在两线间那截被收成全休止 | 任一头 0.4 格内有符干就不收（整小节休止、字典两路都过这道） |
| 谱号盒里的符头 | 谱号自举 | 低音谱号圆头成了 G3 全音符、高音谱号底下的圆球成了黑符头 | 中心落在谱号盒里就作废（原来要整盒在里面） |
| 歌词行里的符头 | 歌词那一段 | 《是谁》「是」字的横笔成了五六条加线下的 G3/C3 | 中心落在认得出汉字的歌词行里、且贴着某个字格才删；只看「落在行里」合唱谱会误删真低音 |
| 没落成音符的符头还给歌词 | 同上 | 字的笔画被认成符头又归不上谱表，那一格字就缺了 | 只看最终音符在不在块里，不看 OCR（条子要与生成缓存时一致） |
| 太高的歌词行 | `lyric.ts::splitTall` | 善牧六段词只隔 0.6 格，1+2、5+6 各并成一条 | 高过块高中位数 1.7 倍，在中间四成找覆盖最少的 y，不到峰值 15% 才切，递归 |
| 附点 | `findDots` | 字典在线距 15~19px 上建的；50px 页的附点被连着符头边抽成横段，11px 页的附点只有 3px | 符头右 0.05~1.3 格、中心上 0.85 下 0.35 格的窗口里，孤立近圆的 0.15~0.6 格墨团；上下一格还有一个的是反复记号 |
| 粗线/终止线 | 页装配前 | 「细+粗」双线：粗线过不了竖段宽度闸、细线过不了孤立性 | 两端贴着顶线/底线（0.4 格内）、宽不过一格、填充八成：补成竖段 |
| 空心头按模板再搜 | `headmask.ts::buildHollowMask` | 「阿们」叠成「8」字的全音符、内腔切成斜缝的全音符 | 本页已认的空心头平均出模板（≥3 个），在**有内腔**的无主块里匹配追踪，门槛 0.38 |
| 和弦撞车 | `textanalyze.ts::attachHarmonies` | 两个和弦抢同一个音，后到的直接丢 | 顺延到 6 格内最近的空闲音 |
| 和弦带里伸上来的东西 | `harmony.ts::withoutRisers` | 谱号顶、符干、加线上的全音符伸进和弦带，读成 `A`/`D` | 从带底往下 0.3 格那一行起灌，灌到的连通块抹掉；不从带底紧下面起灌（真和弦的升号会探出 1px） |
| `<chord/>` 挂错音 | `staffomr/toxml.ts::emitVoices` | 按音高重排之后，带 `<chord/>` 的排到了第一个，和弦顶音挂到前一拍 | 按写出次序定：同组第二个起才带 |

**试过、撤了的**：
- 并内腔设 1 格高上限（想救「8」字全音符）：内腔在 11px 页上是斜缝，还卡在「横宽」闸上，零收益。
  换成上面的模板搜索才救回来。
- 粗线要求至少 0.3 格宽、附点只在谱表附近找：各自让干净档掉 0.1~0.45 点，换来扫描件歌词 +0.17，撤。

## 测评口径：多声部谱规范展开（`node-harness.mjs::xmlByOnset`）

同一个 SATB 和弦，GT 按声部写（女高一整小节、backup、女低……），识别侧按和弦写。
两种都对，扁平序列却对不上（善牧没改口径前音符 25%，量的全是写法差）。
**GT 是多声部时两侧都展开**成「谱表 → 拍位 → 音高从高到低」，和弦附音拆开。单声部曲子不动。

## 《赞美一神》：闭合谱的几处通病

SATB 闭合谱（高音谱表女高女低、低音谱表男高男低），女高下方印一行简谱（没有接互证：
简谱行在谱表**下方**，`findJianpuBands` 只找上方；五线谱这边已经 100%，不急）。
底稿音符 39%，逐条：

| 条目 | 位置 | 病例 | 判据 |
|---|---|---|---|
| 谱号碎块并过了头 | `rasterglyphs.ts::bootstrapClefs` | 花括号下端的弯钩借低音谱号左边一截碎块搭进来，盒拉高到 5.4 格判成高音谱号，整行低音按高音读 | 与种子块 x 不重叠的碎块，上下要贴着（半格内）才并。**不能一律要求贴着**：扫描件谱号断得碎，一律要求时扫描件音符 67.7% → 51.7% |
| 粗升号被当符头 | 调号兜底 + 谱号左侧那一段 | 粗体升号两道横笔去掉竖笔后是两个叠着的黑头（F#3/A3 和弦），或只剩一个 | 谱号右 2 格内：一对（x 差 < 0.3 格、隔 0.7~1.3 格）有两根竖笔贯穿、探出不过一格；单个要上下都探出 0.3 格、最长 1.6 格。符头连符干那一路出得晚，调号兜底之后再验一次 |
| 谱号左边的「全音符」 | 附点那一段之前 | 花括号顶上的弯钩成了 G3 全音符 | 谱号左边不收符头 |
| 空心头宽度 | 空心头模板搜索 | 粗体全音符宽 1.91~1.96 格，过不了 1.9 | 上限 2.2 |
| 符尾远端 | `bootstrapFlags` | 和弦共干 D4/D3，拿 D3 量远端量到了 D4 那头，D4 连着加线把窗口填满，整批读成八分；加线、谱线把符干切成两截，中间那截两头都是符头 | 远端按符干上**所有**头定；两端都贴着头（0.75 格内）的一截不找符尾 |
| 同音两声部 | `splitUnisons` | 一个头右边朝上的干、左边朝下的干，是女高女低唱同一个音 | 出两个音。左右要分清：共干和弦的干被中间的头切成两段，下段对上头也「朝下」，但它在右缘 |
| 和弦带吃符头 | 和弦认领 | 低音谱表上方带加线的男高 D4 整条被认领（OCR 读出几个字符、文法一个不收） | 切不出记号的条不认领；**只给系统首行切和弦带**（谱表左端的系统线从上一行连下来的不切） |
| 低处、高处的和弦字母 | `harmony.ts` | 「阿们」两小节的 C、G 离顶线 0.25 格，被当成伸上来的东西抹掉；延长记号上方的 G 顶被带顶切掉、又与记号并成一条读成「5」 | 带底下探到顶线上方 0.15 格，「伸上来」改成连着谱表的才算，整块在原带底以下的另外丢掉；碰带顶的簇往上长（≤1.5 格）；簇内上下隔开的只留最上一段 |
| 短小节分声部 | `notedata.ts::checkBars` | 与弱起配套的三拍末小节，男高「四分 + 两个八分」、男低「两个八分 + 四分」，拿四拍去凑两趟都凑不满 | 同系统另一行同一小节的和（≥ 半小节、整拍）当长度再凑；本小节和要超过它三成（真挤着两个声部）。不加后一条，宁静十来处单声部短小节被改成按拍位写，音符反掉 |
| 同和弦要挨着写 | `staffomr/toxml.ts::emitVoices` | 不按拍位写的小节，A4/F#4 里带 `<chord/>` 的 A4 排在前面，挂到了前一拍 | 同组挨着、主音打头，`<chord/>` 按写出次序定（与按拍位那一支同一条） |
| 歌词：半字、扁笔、大字 | `lyric.ts` | 宋体左右结构的字偏旁隔 0.3 字宽，一行 19 字切成 31 格，OCR 的字摊错位，整行往左错两个音；「一」「上」的横笔被当成横段抽走；「美」2.6 格高过了 2.4 的上限 | `squareCells`：相邻两格合起来不过 1.4 字宽（字宽取全页、本行 85 分位、本行字高三者最大）、缝不过 0.35 字宽就并，尾随标点并进前一字；没人要的横段竖段也当块；扁块（高 < 0.28 格、宽 ≥ 0.7 格）不参与切行与量字号，切完行按 y 落进去；字高上限 2.8 格 |
| 歌词里的演奏记号 | 字典那一路 | 「上」「军」底下那一横被认成保持音，字缺一笔 | 离所有谱表四格半开外的 `artic*` 不收、不记账 |
| 符杠断头当符头 | 判别器补头 | 歌词那几条一改，《是谁》朝下八分音符的符杠末端露了出来（原先被歌词行那道闸顺手剔掉），出了个 B3 | 块中心压在某条符杠中线上（半个杠厚内）的不收 |

合唱谱那几条歌词改动的净账：干净档歌词 +2.6、扫描件 +2.8（缓存重跑过）。

## 还没解决的（善牧恩慈歌）

- 11px 线距下的空心二分头：男高男低共用的朝下符干因为两个头没认出，被当成了小节线；
- 临时升号（C♯4、D♯4）漏认；男声那几对八分音符的时值与位置；
- 带加线的全音符被认成黑符头、贴线的全音符被去谱线切成两半（内腔找不到，模板搜索的先验不成立）。
- 《赞美一神》：和弦 19/20（一个没对上位置）、挂位 87%；谱表下方的简谱行没接互证。

## 1. 五格式原生编辑的剩余

`.pu` / `.jpwabc` / `.123` / `.abc` / `.musicxml` 五种格式都已原生打开、编辑、存回原格式，外加文本 ↔ 谱面的双向定位。
各格式的排版、试听、导出都从唯一的模型 `ScoreDoc` 出（分工见 [模块/模型-scoredoc.md](模块/模型-scoredoc.md)）。

### 1.1 已知的表达限制

- 123 那一档的**拉丁歌词**仍是连写（`AbcFamilyEmitter.lyricSeparator` 为空串）。
  中文语料碰不到；要改得连 `parseLyricLine` 一起看，否则往返会多出音节。
  **验**：`abc-roundtrip.mjs` 加一份英文歌词夹具，往返音节数不变。
- `.musicxml` 的**简谱展开档不画小节线**：MusicXML 形状投成简谱行（`pu/slots.ts::docView` 经 `jianpuproject.ts`）后，
  行里没有普通小节线元素，`jianpuInputOfDoc` 按小节线切小节，整行并成一两个大小节，谱面只在双线/终止线处有线
  （原样档 `PuPainter` 按模型小节画，不受影响；123/ABC 来源写出了 `|`，也不受影响）。曲中转调因此只在恰好落在
  这类小节线上时才画得出来。
  **验**：`jianpu-svg-dump --only=xml` 的差异逐份看是补出小节线；`page-check` 与 `pptx-check` 不回退。
- 文本谱/123/ABC 的**试听不认曲中转调**：`model/playsong.ts::songMeasures` 全曲只用头部调号推音高（谱面已按模型小节画出转调）。
  **验**：一份曲中 `1=G → 1=D` 的 123 夹具，`play-check` 转调后的音高按新调算。
- `Chord.lineBreakAfter`（小节中间换行）：简谱引擎与 MusicXML 投影（拆成两个小节）已认；
  123 / `.jpwabc` 写出端仍按小节级换行写（行内 `$` 挪到小节末）。
  **验**：`jpw-emit-check` 的 `.jpwabc` 往返定点之外，另比「写出 → 读回」的行内换行位置不变。

## 3. 重构路线

由 [架构.md](架构.md) 的「两条主线」与 [格式/123格式.md](格式/123格式.md) 推出，优先级已定：

| | 事项 | 为什么 | 验 |
|---|---|---|---|
| **R3** | 成书排版进 app（`src/pdflayout/` 提升为库） | 整本排版目前只有 CLI；顺带接上悬空的 `isVectorPdf` | `rebuild.mjs` + `line-check.mjs` 零回退；编辑器能进「诗歌本」视图 |
| R5 | 跨行 slur/tie 被静默丢弃 | `Line.chordEntry` 只认本行，另一端在别的行就 `continue` | 拿一首跨行弧的谱看渲染；`page-check.mjs` |
| R7 | 退役 `PuPainter`：只留一个具体 `ScorePainter`（设计与分阶段计划见 [实现/PuPainter退役.md](实现/PuPainter退役.md)） | 123/ABC 单声部已走引擎；剩多声部同组（按拍位对齐）、临时层 `{bz}`/`{dsb}`、`W:` 文字行、页脚 `BL/BC/BR` 要补进引擎，文本谱原版栅格（`pu/metrics.ts`）写成样式表 | 文本谱语料原样档逐首目检；`sync-check` / `play-check` 原样档全过；删掉 `pu/painter.ts`、`pu/layout.ts` |
| R6 | `.jpwabc` 两条既有缺陷（`{C:…}` 污染解析 / `::` 抛错） | 568 首语料实测**均 0 例**，故优先级低 | 各加一份夹具，解析不抛错、音符不多不少 |

R1（统一样式层）已落地：`src/style/` 的样式表 + 级联 + 主题，四把尺子降为适配器，编辑器面板改写用户层，
几何基线零变化。剩下的（页位/段号限定的消费者、「校对对照」主题、`overrides` 的界面、文本谱 `Space:`/`Off:`）
记在 [样式机制.md](样式机制.md) §8，歌本 `.jpcss` 与数据/模板两层见 §2.3。

R2（语义模型 `ScoreDoc`）已收尾：它是唯一的模型，简谱引擎读它投影出的只读输入（`model/jianpuinput.ts` → `layout/input.ts`），
五线谱引擎只留版面态（`mixed/model.ts::StaffLayout`）。剩下的尾巴在 §3.1。

### 3.1 模型这条线还剩的

- **五线谱接断句**（暂缓）：同一套断句只取小节级断点（`useMidBreaks: false`），`FitMetric` 由混排引擎量。
  **验**：挑几首五线谱诗歌看分行；断点集合与简谱档的小节级子集一致（除容量补刀）。
- **断点写回 `ScoreDoc`**：暂无消费者（成书写进引擎输入、编辑器改写原文）。真要存的时候，小节级进 `Print.newSystem/newPage`，
  行内的沿用 `Chord.lineBreakAfter`，能力表加一项（MusicXML 装不下行内换行，`planSave` 提示）。
  **验**：写回后 `toxml` / `emit123` 重读，断点集合不变。
- **`ScoreDoc` 仍丢的版面属性**：`layout-attr-check` 的「仍丢」表（2026-09-14 实跑）——`<credit-words>` 的字体族/`valign`/`xml:space`、
  `<defaults>` 的 `music-font`/`lyric-font`、`<supports>`、`part-name print-object`、`group-symbol default-x`、
  `slur` 的贝塞尔与坐标、`fermata`/`accent` 坐标、`ending` 的 `default-y`/`end-length`/字号/`print-object`、`repeat winged`、
  `harmony` 字体、`measure-numbering` 属性、`<sound>` 的 `divisions`/`dynamics`、`bass arrangement`。
  只影响 `.musicxml` 改动后整份重写的版面还原，排版不读。
  **验**：该表逐项清掉，568 份「改一个音 → 整份重写」计数一致。

**原则**（后续改模型时守住）：
- **派生量不存进 `ScoreDoc`、只经查询层取**（唱名、减时线条数、调号上下文…，见 `model/jianpu.ts`）：同名字段两种口径
  （`Chord.beams` 在 MusicXML 来源是 `<beam>` 列表、在简谱来源是减时线条数，靠 `isXmlShaped` 分）；存了要管编辑后的失效；
  指针有环不能序列化。**断行与版面坐标例外**——它们是「这份谱怎么印」的事实，要随文档保存、往返。
- 简谱引擎输入的三个分支（MusicXML 形状 / 简谱形状 / `.jpwabc`）各有观感差异（`.jpwabc` 小节线不画样式、MusicXML 只取第一声部、
  简谱形状的展开档不画和弦），**不在输入这一层抹平**；要统一观感就动绘制层，改动以 `jianpu-svg-dump` 逐页指纹为判据、差异逐份定性。

## 3.2 可视化编辑的后续

谱面上直接改谱已覆盖四种文本格式（[模块/编辑器与播放.md](模块/编辑器与播放.md)「可视化编辑」）。还没做的：

- **歌词录入模式**：选中音符后 `Ctrl+L` 进入逐字录入，空格跳到下一个音符，`/` 跳过一个音符（这就是 `/` 没绑定成快捷键的原因），`-` / `_` 续唱。
  四种格式的歌词写法各不同（123 的 `w:`、`.jpwabc` 的 `.Words` 锚点、文本谱的 `C:`、ABC 的 `w:`），落点照样进 `EditDialect`。
  **验**：四种格式各一份夹具，录入一段词后重新解析，`docView` 的 `syllableOwner` 对位与期望一致；撤销逐字还原。
- **选区整体移调 / 移八度，复制粘贴一段音符**：剪贴板存源码片段，跨格式粘贴时由 dialect 转写（ABC 音名 ↔ 唱名、`.jpwabc` token 内增时线）。
  **验**：选中一段移调后再移回，原文逐字还原；从 123 复制粘贴到文本谱，重新解析后度数、时值一致。
- 增时线、小节线、圆滑线在谱面上还没有自己的 `<g>`（借宿主音符的定位），点不中它们本身；统一 ScorePainter 的 `locate`/`elementsOf` 落地后改接。
  **验**：谱面上直接点增时线、弧线能选中它们；可视化编辑回归不回退。

## 4. 上游限制（不是 123 的账，但影响迁移质量）

这几条都在 123 之外，修它们要动既有解析器，各自有自己的回归基线：

| 限制 | 影响 | 现状 |
|---|---|---|
| `parsePu` 不保留 `"1."` 这类段号标记的 annotation | 1932 份记为「降级表达」 | 迁移报表已区分，不误报成规范缺口 |
| 段号区间（`W1-6:` / `C1-2:`）123 不表达 | 一行词供多段共用时逐段各抄一遍 | 刻意如此（123 规范 §11：ABC 只有裸 `w:`） |
| MusicXML 原文残缺 | 084 只有一个 `type="stop"` 的 `<ending>`、没有起头，123 表达不了 | 迁移报表记「降级表达」 |

## 1. 五格式原生编辑的剩余

`.pu` / `.jpwabc` / `.123` / `.abc` / `.musicxml` 五种格式都已原生打开；文本谱/123/ABC 的排版、`Score`、
MusicXML 导出、双向定位、试听高亮**全部直接吃 `ScoreDoc`**（`PuDoc` 只剩解析器产物与乐句重排两处），
`.musicxml` 打开无代码区、改动整份重写；MusicXML 只有一份写出端（`model/toxml.ts`）。
**做过什么、各自的验数在 [进度.md](进度.md)**。

### 1.1 已知的表达限制

- 123 那一档的**拉丁歌词**仍是连写（`AbcFamilyEmitter.lyricSeparator` 为空串）。
  中文语料碰不到；要改得连 `parseLyricLine` 一起看，否则往返会多出音节。
  **验**：`abc-roundtrip.mjs` 加一份英文歌词夹具，往返音节数不变。
- `.jpwabc` 的双向定位仍只到小节级：`Score` 不带源偏移。
  **验**：`sync-check.mjs` 加 `.jpwabc` 两档，文本→谱面、谱面→文本命中率与 123 那档同口径。

## 2. 123 语料迁移的剩余

### 2.1 残留的往返不幂等（0.15%）

跑 `PU_CORPUS=… HYMN500=… node scripts/j123-migrate.mjs` 看 `testdata/j123-coverage.md`。
已知模式（每类 1–2 份）：

| 现象 | 样本 |
|---|---|
| `$` 与小节线顺序 | `赞美诗增订本/0101_十字架` |
| 多连音起点与 `$` 相邻时错位 | `赞美诗增订本/0133_耶稣升天` |
| 歌词末尾标点归属 | `赞美诗歌1300/0632_活出生命的色彩` |
| `I:space` 指令值被吞 | `教会诗声/0149_主耶稣在世七步路` |

**验**：全量迁移后 `往返不幂等` 计数下降，且既有的 568/568（500 首两路）不回退。

### 2.2 残留的「无法表达」（0.14%）

| 项 | 份数 | 样本 |
|---|---:|---|
| 文字行 `W:` | 9 | `个人上传/8669_我从前风闻有你` |
| 圆滑线 | 5 | `选本诗歌附录版/0091_我的主我心爱祢` |
| 多段歌词 | 5 | `赞美诗增订本/0005_你是我的主` |

**每条都要先判是哪一类**：123 规范表达不了（改规范）、转换层漏了（改代码）、
还是上游解析器没读进来（见 §4，不是 123 的账）。报表已经会区分后者，但这 25 份还没逐个看过。
（印刷段号 4 份、倚音 2 份已随 `frompu.ts` 无损化消掉：段号原来只挂首音节、首音节为空就丢；倚音原来丢了升降号与时值。）

### 2.3 书级：`book.toml` 与 `book.jpcss`

[格式/123格式.md](格式/123格式.md) 定了 500 首的存储布局（一首一文件 + 书清单 + 书级样式表），
但 `book.toml` 的字段与 `book.jpcss` 的语法都还没落地。前者要能表达曲号→文件、分类、目录、
索引、扉页、装箱规则；后者见 [样式机制.md](样式机制.md)。

**验**：用它重跑 `scripts/rebuild.mjs` 的整本排版，`line-check.mjs` 全书基线零回退。

## 3. 重构路线

优先级与理由在 [进度.md](进度.md) 的「下一步」表里，这里只记判据：

## 4. 上游限制（不是 123 的账，但影响迁移质量）

这几条都在 123 之外，修它们要动既有解析器，各自有自己的回归基线：

| 限制 | 影响 | 现状 |
|---|---|---|
| `parsePu` 不保留 `"1."` 这类段号标记的 annotation | 1932 份记为「降级表达」 | 迁移报表已区分，不误报成规范缺口 |
| `Score` 把 `W1-6:` 段号区间展开成逐段 | 区间写法还原不回去 | 同上 |
| `loadMusicXml` 个别 slur/ending 未读入 | 2 首（362 的 2 个 slur、084 的 1 个 ending） | 同上。**直通那条路（`fromxml.ts`）没有这个问题**——568 份的 `<slur>`/`<ending>` 计数一个不少 |
| `scoreDocToScore` 丢和弦/力度/多声部 | 文本谱/123/ABC 那一路 | 已知取舍，所以 MusicXML 导出绕开 Score 直出 |
